# なぜTransformerなのか — RNNの問題点

> RNNはトークンを1つずつ処理する。Transformerはすべてのトークンを一度に処理する。このたった1つのアーキテクチャ的な賭けが、2017年以降のディープラーニングのあらゆるスケーリング曲線を変えた。


## 問題

2017年以前、地球上のあらゆる最先端シーケンスモデル（言語・翻訳・音声）は再帰型ニューラルネットワーク（RNN）だった。LSTMとGRUは半十年にわたってImageNetに匹敵する翻訳ベンチマークを制し続けた。それ以外に選択肢はなかった。

RNNには3つの致命的な弱点があった。逐次計算のため、時間軸方向の並列化ができなかった：トークン`t+1`にはトークン`t`の隠れ状態が必要だ。1,024トークンのシーケンスは、1サイクルで1,000,000の浮動小数点演算が可能なGPU上で1,024ステップの逐次処理を意味する。並列処理のために設計されたハードウェアで、学習の実時間はシーケンス長に対して線形にスケールした。

勾配消失により、50トークン前の情報は50の非線形変換を通じてすでに圧縮されていた。ゲート付き再帰ユニット（LSTM、GRU）はこの問題を和らげたが、根絶することはなかった。長距離依存関係——「去年の夏、京都行きの飛行機の中で読んだ本は…」——は日常的に失敗していた。

固定幅の隠れ状態により、エンコーダはデコーダが何かを見る前にソースシーケンス全体を単一のベクトルに圧縮しなければならなかった。ソースが5トークンであろうと500トークンであろうと、ボトルネックの形は同じだ。

2017年の論文「Attention Is All You Need」は革命的な提案をした：再帰を完全に排除する。すべての位置が並列に他のすべての位置にアテンションを向けられるようにする。1,024回の逐次演算の代わりに、1つの大きな行列積で学習する。

その結果は2026年までにあらゆるモダリティを支配している。言語（GPT-5、Claude 4、Llama 4）、視覚（ViT、DINOv2、SAM 3）、音声（Whisper）、生物学（AlphaFold 3）、ロボティクス（RT-2）。同じブロック、異なる入力。

## 概念

![RNNの逐次計算 vs Transformerの並列Attention](../assets/rnn-vs-transformer.svg)

**ボトルネックとしての再帰。** RNNは`h_t = f(h_{t-1}, x_t)`を計算する。各ステップは前のステップに依存する。`h_5`を`h_4`の前に計算することはできない。10,000以上の並列コアを持つ現代のGPU上では、長いシーケンスで99%のシリコンが無駄になる。

**ブロードキャストとしてのAttention。** Self-Attentionはすべてのペア`(i, j)`に対して`output_i = sum_j(a_ij * v_j)`を同時に計算する。N×Nのアテンション行列全体が1つのバッチ行列積で埋まる。あるステップが別のステップに依存することはない。GPUはそれが大好きだ。

**高速化は定数倍ではない。** それは`O(N)`の逐次深さと`O(1)`の逐次深さの差だ。実際には、N=512のマッチしたハードウェアで、Transformerはエポックあたり5〜10倍速く学習する。そしてアテンションの`O(N²)`メモリウォール（後にFlash Attentionが解決した——レッスン12を参照）に達するまで、この差はシーケンス長とともに広がる。

**Transformerのコスト。** アテンションメモリは`O(N²)`にスケールする。2Kコンテキストには問題ない。128Kコンテキストには、スライディングウィンドウ、RoPE外挿、Flash Attentionタイリング、または線形アテンション変形が必要だ。再帰は時間とメモリの両方で`O(N)`だった；Transformerはメモリと引き換えに時間を取り、並列性を通じて時間を取り戻す。

**帰納的バイアスのシフト。** RNNは局所性と近接性を仮定する。Transformerは何も仮定しない——すべてのペアがアテンションの候補だ。だからTransformerはうまく学習するのにより多くのデータを必要とするが、データがあれば無限にスケールする。Chinchilla（2022年）はこれを形式化した：十分なトークンがあれば、同じパラメータ数のRNNに対してTransformerは常に勝つ。

## 実装する

ここにニューラルネットワークはない——コアのボトルネックを数値的にシミュレートして、ラップトップでその差を体感する。

### ステップ1：逐次深さを測定する

`code/main.py`を参照。2つの関数を作る。一方はシーケンスを加算の連鎖としてエンコードする（逐次、RNNのように）。もう一方は並列リダクションとしてエンコードする（ブロードキャスト、アテンションのように）。同じ数学、異なる依存グラフ。

```python
def rnn_style(xs):
    h = 0.0
    for x in xs:
        h = 0.9 * h + x   # can't parallelize: h depends on previous h
    return h

def attention_style(xs):
    return sum(xs) / len(xs)  # every x is independent
```

両方を最大100,000要素のシーケンスで計測する。RNNバージョンはO(N)で単一CPUパイプラインだ。純粋なPythonでも、長さ≥1,000でattention_styleの削減がそれに勝る。なぜなら、Pythonの`sum()`はCで実装されており、ステップごとのインタープリタオーバーヘッドなしにイテレートするからだ。

### ステップ2：理論的な演算数を数える

両アルゴリズムともN回の加算を行う。違いは*依存深さ*だ：次が始まる前に逐次に実行しなければならない演算の数。RNNの深さ = N。ツリーリダクションによるアテンションの深さ = log(N)、または並列スキャンで1。GPU時間を決めるのは演算数ではなく深さだ。

### ステップ3：長いシーケンスでの実証的スケーリング

O(N)のギャップを可視化するタイミングテーブルを出力する。2026年のMacラップトップでは、1,000要素未満のシーケンスは速すぎて測定できない。100,000要素のシーケンスはきれいな線形スキャンを示す。それを12層LSTMに相当する16,384トークンのTransformerにスケールすると、2016年に学習時間がボトルネックだった理由がわかる。

## 使ってみる

2026年にもRNNを選ぶべき場面：

| 状況 | 選択 |
|-----------|------|
| ストリーミング推論、1トークンずつ、定数メモリ | RNNまたは状態空間モデル（Mamba、RWKV） |
| アテンションメモリが爆発する非常に長いシーケンス（>1Mトークン） | 線形アテンション、Mamba 2、Hyena |
| 行列積アクセラレータのないエッジデバイス | 深さ方向分離可能RNNがFLOPs/ワットでまだ勝る |
| それ以外すべて（学習、バッチ推論、128Kまでのコンテキスト） | Transformer |

Mambaのような状態空間モデル（SSM）は、本質的に構造化パラメータ化されたRNNであり、両方の長所を持つ：`O(N)`スキャンメモリ、選択的スキャンによる並列学習。同等パラメータ数のTransformerの品質の90%を、より優れた長距離コンテキストスケーリングで実現する。2026年、ほとんどのフロンティアラボはSSM+Transformerのハイブリッドモデル（例：Jamba、Samba）を学習している——再帰は死んでいない、コンポーネントとなっているだけだ。

## 成果物を出す

`outputs/skill-architecture-picker.md`を参照。このスキルは、長さ・スループット・学習予算の制約を与えられた新しいシーケンス問題に対してアーキテクチャを選択する。学習実行が1Bトークンを超える場合、トレードオフを明示せずに純粋なRNNを推奨することは絶対に拒否すべきだ。

## 演習

1. **易.** `code/main.py`の`rnn_style`を取り、スカラー隠れ状態を長さ64の隠れ状態ベクトルに置き換えよ。再計測せよ。隠れ状態の次元とともに逐次オーバーヘッドはどれだけ増加するか？
2. **中.** 純粋なPythonで並列プレフィックスサム（Hillis-Steeleスキャン）を実装せよ。長さ1024で逐次スキャンと同じ数値出力が生成されることを確認せよ。深さを数えよ。
3. **難.** attention_styleリダクションをGPU上のPyTorchに移植せよ。シーケンス長を64から65,536まで変化させながら両方を計測せよ。プロットして曲線の形を説明せよ。

## キーワード

| 用語 | 人々が言うこと | 実際の意味 |
|------|-----------------|-----------------------|
| 再帰（Recurrence） | 「RNNは逐次」 | ステップ`t`がステップ`t-1`に依存する計算で、時間軸に沿った逐次実行を強制する。 |
| 逐次深さ（Serial depth） | 「グラフの深さ」 | 依存する演算の最長連鎖；無限のハードウェア上でも実時間を制約する。 |
| アテンション（Attention） | 「トークン同士が互いを見る」 | 加重和`sum_j a_ij v_j`。`a_ij`は位置iとjの類似スコアから来る。 |
| コンテキストウィンドウ（Context window） | 「モデルが見られる範囲」 | アテンション層が入力として取れる位置の数；二次メモリコストがここでスケールする。 |
| 帰納的バイアス（Inductive bias） | 「アーキテクチャに焼き込まれた仮定」 | データがどんな形かについての事前分布；CNNは平行移動不変性を仮定、RNNは近接性を仮定。 |
| 状態空間モデル（State-space model） | 「代数を持つRNN」 | 構造化状態空間行列を通じた並列学習のために構造化パラメータ化された再帰。 |
| 二次ボトルネック（Quadratic bottleneck） | 「なぜコンテキストがコストがかかるか」 | アテンションメモリ = シーケンス長で`O(N²)`；Flash Attentionは定数を隠すがスケーリングは隠さない。 |
