# Tree of ThoughtsとLATS: 意図的な探索

> 単一のchain-of-thoughtトラジェクトリには、バックトラックする余地がない。ToT（Yao et al.、2023）は推論を各ノードで自己評価を持つ木に変える。LATS（Zhou et al.、2024）はモンテカルロ木探索の下でToTをReActおよびReflexionと統合する。Game of 24は4%（CoT）から74%（ToT）になり、LATSはHumanEvalでpass@1 92.7%を達成する。


## 学習目標

- 推論を探索としてフレーミングする: ノードは「思考」、エッジは「展開」、値は「どれだけ有望か」。
- 自己評価スコアリングを持つstdlib ToTスタイルのBFS木探索を実装できる。
- select / expand / simulate / backpropagateを持つトイLATS MCTSループに拡張できる。
- 探索がトークン倍率に見合う場合（Game of 24、コード生成）と、単一トラジェクトリで十分な場合（シンプルなQ&A）を決定できる。

## 課題

Chain-of-thoughtは線形歩行だ。最初のステップが間違っている場合、以降のすべてのステップは誤った前提で動作する。Game of 24（4つの数字を+−×÷で使って24を作る）では、GPT-4のCoTは4%の精度しか達成しない。モデルは早い段階で間違った部分式を選び、回復できない。

推論に必要なのは、複数の候補を提案し、それらを評価し、有望なものを選び、行き詰まりが現れたときにバックトラックする能力だ。それが探索だ。Tree of ThoughtsとLATSは2つの標準的な定式化だ。

## コンセプト

### Tree of Thoughts（Yao et al.、NeurIPS 2023）

各ノードは一貫した中間ステップ（「思考」）だ。各ノードはK個の子思考に展開できる。LLMはスコアリングプロンプトで各ノードを自己評価する。探索は木を探索する—BFS、DFS、またはビーム。

```
                     (root: "4 6 4 1から24を見つける")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- スコア: 高
              /   \              |                  |
          ...    ...          ...                finish
```

自己評価が重要な部分だ。論文は3つのバリアントを示す: `確実 / 可能性あり / 不可能` の分類、`1..10` の数値スコア、候補間の投票。3つすべてがGame of 24でCoTを大幅に上回る（GPT-4で4% -> 74%）。

### LATS（Zhou et al.、ICML 2024）

LATSはMCTSの下でToT、ReAct、ReflexionをLLMがで3つの役割を担う形で統合する:

- **ポリシー**: ReActスタイルの候補次アクションを提案する。
- **価値関数**: 部分トラジェクトリをスコアリングする（ToTスタイルの自己評価）。
- **Self-reflector**: 失敗時に自然言語のリフレクションを書き、将来のロールアウトを再シードするために使用する（Reflexionスタイル）。

環境フィードバック（観察）が価値関数に混ざるため、探索はモデルの意見だけでなく実際のツール結果に基づいて情報を得る。論文時点の結果: GPT-4でHumanEval pass@1 92.7%（SOTA）、GPT-3.5でWebShop平均75.9（勾配ベースのファインチューニングに近い）。

### MCTS、最小限に

イテレーションごとの4フェーズ:

1. **Select（選択）** — UCT（木のための上限信頼境界）を使ってルートからリーフまで歩く。
2. **Expand（展開）** — ポリシーを介してK個の子を生成する。
3. **Simulate（シミュレート）** — ポリシーを使ってリーフからロールアウトし、価値関数（または環境報酬）でリーフをスコアリングする。
4. **Backpropagate（逆伝播）** — パスに沿って訪問カウントと価値推定を更新する。

UCT式: `Q(s, a) + c * sqrt(ln N(s) / N(s, a))`。第1項は活用; 第2項は探索。タスクごとに `c` を調整する。

### コストの現実

探索はトークンを爆発させる。Game of 24でのToTはCoTの100〜1000倍のトークンを使う。LATSも同様だ。これは無料ではない; 探索を使うのは以下の場合だけにする:

- 単一トラジェクトリが明らかに不十分なタスク（Game of 24、複雑なコード）。
- 正確性よりウォールクロックの方が重要度が低いタスク。
- 安くて信頼できる価値関数があるタスク（コードのユニットテスト、数学の明示的な目標）。

タスクに単一の正解があり、評価器がノイジーな場合、探索はしばしば事態を悪化させる—「高スコア」の誤答を見つける。

### 2026年のポジショニング

ほとんどの本番エージェントはLATSを実行しない。ツール根拠の検証でReActを実行する（CRITIC、レッスン05）。探索は特殊なニッチに現れる:

- テストを価値関数として実行するコーディングエージェント（HumanEvalスタイル）。
- 複数のクエリパスを探索する深い調査エージェント。
- LangGraphサブグラフ内のプランニング重い処理。

AlphaEvolve（レッスン11）は2025年の極端な例: コードに対する進化的探索、機械チェック可能なフィットネス、フロンティアの成果（56年ぶりの4x4行列乗算の最初の改善）。

## 実装する

`code/main.py` は以下を実装している:

- スタイル化された「算術演算を選ぶ」タスクでの小さなToT BFS。
- 同じタスクでのトイLATS MCTSループ（Select / Expand / Simulate / Backpropagate）とUCT選択。
- シンボリックスコアと自己評価スコアを合成する価値関数。

実行:

```
python3 code/main.py
```

トレースはToTがノードごとに3つの候補をBFSで展開し、LATSがMCTSを介して最良のロールアウトに収束する様子を示す。両方のトークン数が印刷される。

## 使ってみる

LangGraphはToTスタイルの探索をサブグラフパターンとして出荷する; LangChainチームのLATSに関するブログ（2024年5月）がリファレンスチュートリアルだ。LlamaIndexは`TreeOfThoughts`エージェントを出荷する。2026年のほとんどの本番エージェントにとって、このパターンは `if task_complexity > threshold: use_search()` ゲートの後ろにある—レッスン05の評価器-オプティマイザーパターンを参照。

## 成果物を出す

`outputs/skill-search-policy.md` は、タスク形状、予算、評価器の忠実度に基づいて線形ReAct、ToT、LATS、進化的探索の中から選択する。

## 演習

1. UCT c=0.1 vs c=2.0でトイLATSを実行する。トレースで何が変わるか？
2. 価値関数をノイジーなスコアラー（ランダムジッターを追加）に交換する。MCTSは依然として最良のリーフを見つけるか？許容できる最小の信号対ノイズ比は何か？
3. ビームサーチToT（各レベルでトップkを保持）を実装し、BFSと比較する。タイトなトークン予算ではどちらが良いか？
4. LATSのセクション5.1を読む。HumanEvalトラジェクトリカウントを再現する: 報告されたpass@1に到達するのに何回のロールアウトが必要か？
5. LATS論文の「LATSが役に立たない場合」についての議論を読む。タスク形状を探索戦略にマッピングする1段落の決定ルールを書く。

## キーワード

| 用語 | よく聞く言い方 | 実際の意味 |
|------|----------------|------------|
| Tree of Thoughts | "分岐CoT" | Yao et al. — 自己評価を持つ思考ノードの木 |
| LATS | "LLMのためのMCTS" | Zhou et al. — MCTSの下でToT + ReAct + Reflexionを統合 |
| UCT | "上限信頼境界" | 活用（Q）と探索（ln N / n）をバランスする選択式 |
| Value function（価値関数） | "この状態はどれだけ良いか" | プロンプトされたLLMスコアまたは環境報酬; 逆伝播に供給 |
| Policy（ポリシー） | "行動提案者" | ReActスタイルジェネレーター; 候補の次の思考/行動を出力 |
| Rollout（ロールアウト） | "シミュレートされたトラジェクトリ" | ポリシーを使ってノードからリーフまで歩き、価値でスコアリング |
| Backpropagate（逆伝播） | "祖先を更新する" | リーフの報酬をパスに沿って押し上げ、訪問カウントとQを更新 |
| Search cost（探索コスト） | "トークン爆発" | Game of 24でCoTの100〜1000倍; 採用前に予算を確認 |
