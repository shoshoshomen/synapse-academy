# エージェント経済、トークンインセンティブ、レピュテーション

> 長期自律エージェント（METRの1時間から8時間の作業曲線）には経済的な代理権が必要だ。新興する**5層スタック**は: **DePIN**（物理的計算）→ **Identity**（W3C DID + レピュテーション資本）→ **Cognition**（RAG + MCP）→ **Settlement**（アカウント抽象化）→ **Governance**（エージェントDAO）。本番エージェントインセンティブネットワークには**Bittensor**（TAOサブネットがタスク固有モデルに報酬）、**Fetch.ai / ASI Alliance**（ASI-1 Mini LLM + FETトークン）、**Gonka**（計算を生産的AIタスクに再割り当てするトランスフォーマーベースのPoW）がある。学術研究: AAMAS 2025の分散型LaMASは**シャプレー値クレジット帰属**を使用して貢献エージェントに公平に報酬を与える; Google Research「Mechanism design for large language models」は単調集約の下で**トークンオークション**と第二価格支払いを提案する。このレッスンでは最小限のエージェントマーケットプレイスを構築し、シャプレー値クレジット帰属をマルチエージェントパイプラインに適用し、第二価格トークンオークションを実行してゲーム理論の機械が具体的に理解できるようにする。


## 問題

マルチエージェントシステムはエージェントが共同で価値を生み出すが個別に報酬を受ける必要がある場合に複雑になる。古典的なメカニズム—均等割り、最後の貢献者が全部取り—は不公平またはゲーム可能だ。シャプレー値による連立報酬は構造的に公平だが計算コストが高い。2025〜2026年の文献は有用な近似を推し進めている: シャプレーサンプリング、単調集約オークション、確認された貢献からのオンチェーンレピュテーション。

クレジット帰属を超えて、この分野は実際の経済エージェントに向かっている: Bittensor TAOはサブネット固有のモデルをファインチューニングするためにマイニング計算に報酬を与え、Fetch.ai/ASIはFETトークンでASI-1 Mini LLM使用に報酬を与え、GonkaはトランスフォーマーPoWを生産的AIタスクに向けて再割り当てする。自律的に取引するエージェントは今日存在している; 問題はインセンティブをどう整合させるかだ。

このレッスンでは、エージェント経済を特定の問題ファミリーとして扱う—クレジット帰属、メカニズム設計、レピュテーション—そして各アイデアが定着するように最小限の数学で構築する。

## 概念

### 5層エージェント経済スタック

1. **DePIN（物理的計算）。** GPU、ストレージ、帯域幅を貸し出す分散型インフラ。Bittensorサブネット、Renderネットワーク、Akash。エージェント固有ではなく; エージェントが使用する。
2. **Identity。** W3C分散型識別子（DID）は各エージェントにいかなるプラットフォームにも依存しない恒久的なIDを与える。レピュテーションはDIDに蓄積する。エージェントネットワークプロトコル（ANP）はDIDを発見層として使用する。
3. **Cognition。** エージェントの推論ループ: LLM + RAG + MCP。他のフェーズが構築するもの。
4. **Settlement。** アカウント抽象化（ERC-4337）はエージェントがETHを保持せずに自分の残高からガスを支払えるようにする。エージェントはサービス、互い、または計算のために支払える。
5. **Governance。** エージェントDAO: 人間*とエージェント*がプロトコル変更に投票し、投票権はレピュテーションに紐付けられるガバナンス構造。

すべての本番システムが5つすべてを使用するわけではない。Bittensorは1、2を使用、部分的に3と4、5はなし。OpenAIエージェントは3以外何も使用しない。スタックは参照マップであって要件ではない。

### Bittensor、Fetch.ai、Gonka — 動いているもの

**Bittensor（TAO）。** サブネットは専門化されたタスク（言語モデリング、画像生成、予測）だ。マイナーはモデル出力を提出する。バリデーターがランク付けし; ステーク重み付きスコアがTAO報酬を分配する。各サブネットには独自の評価がある。経済的教訓: 使用した計算ではなく、タスク固有の出力品質に支払う。

**Fetch.ai / ASI Alliance。** ASI-1 Mini LLMはFetch.aiのネットワークで動作し; ユーザーは推論のためにFETトークンを支払う。ピアとしてのエージェントのナラティブはここでより強い: Fetchのエージェントは別のエージェントにタスクを呼び出し、FETで支払える。

**Gonka。** トランスフォーマーPoW: 「仕事」はトランスフォーマーのフォワードパスだ。マイナーは既知の正しい出力（学習データから）を持つ推論タスクを実行することで稼ぐ。ハッシュベースのPoWの代わりにリソース生産的PoW。

3つすべてが2026年4月現在で本番グレードだ。支払い分配は異なる。Bittensorはサブネットバリデーターに対する品質に基づいて報酬; Fetchは支払いユーザーが測定するユーティリティに基づいて報酬; Gonkaは検証可能な推論作業に基づいて報酬。

### シャプレー値クレジット帰属

3つのエージェントがタスクで協力する。出力が0.8をスコアリングする。誰が何を貢献したか？

シャプレー値: 4つの公理（効率性、対称性、線形性、null）を満たす唯一のクレジット割り当て。エージェント `i` のために:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

ここで `S_i_O` は順序 `O` でのエージェント `i` の前のセット。実際には: すべての置換を列挙し、各置換での各エージェントの限界貢献を記録し、平均を取る。

N=3エージェントでは、6置換がある。N=10では、360万—実際には置換を列挙する代わりにサンプリングする。

### 集約のための第二価格オークション

Google Research（「Mechanism design for large language models」）はLLM出力を集約するために第二価格トークンオークションを提案する。設定: N個のエージェントがそれぞれ補完を提案し; 各エージェントは選択された際に私的価値を持つ。オークショナーが最高価値の提案を選び、*第二最高*価値を支払う。単調集約の下（価値はどれが提案されたかに依存し、いくつ入札されたかではない）、これは誠実—エージェントは真の価値で入札する。

これがLLMシステムにとって重要な理由: 異なる価格設定の複数のエージェントに補完タスクを委託できる; オークションが最良を選択 + 公平に支払い、エージェントは誤って報告するインセンティブがない。

### レピュテーション資本

DIDに紐付けられたレピュテーションスコアが確認された貢献から蓄積する。シンプルな更新ルール:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

1に近い減衰係数 `alpha` で。レピュテーション:

- ルーティング決定のために読むのが安価（「難しいタスクを高レピュテーションエージェントに送る」）。
- 偽造するのが高価（時間とともに蓄積、DIDに紐付けられる）。
- スラッシュ可能: 検証に失敗した貢献は減点される。

### AAMAS 2025 分散型LaMAS

LaMASの提案（AAMAS 2025）は以下を組み合わせる: DIDアイデンティティ、シャプレー値クレジット帰属、シンプルなオークションメカニズム。主な主張: クレジット帰属ステップを分散化することでシステムが監査可能になり、単一点操作に対して免疫が付く。

### 経済が崩壊する場所

- **価格オラクル操作。** クレジット関数をゲームできれば、エージェントはゲームする。すべてのメカニズムには敵対的テストが必要だ。
- **シビル攻撃。** 1人のオペレーターが自分の貢献を膨らませるためにN個の偽エージェントを立ち上げる。DIDは遅らせるが止めない; レピュテーションの偽造コストが緩和策だ。
- **検証コスト。** クレジット帰属は検証者と同程度にのみ公平だ。検証が安価（小さなLLM）であればゲームできる; 高価（人間パネル）であればシステムがスケールしない。
- **規制の不確実性。** エージェント経済は金融規制と交差する。Bittensor、Fetch、Gonkaはすべて2026年のいくつかの管轄区域で法的グレーゾーンで運営している。

### エージェント経済が意味をなす場合

- **異種オペレーターを持つオープンネットワーク。** 単一チームがすべてのエージェントを制御しない。
- **検証可能な出力。** 検証なしでは、クレジット帰属は推測だ。
- **長期ワークフロー。** 単発タスクはレピュテーション蓄積の恩恵を受けない。
- **トークン支払いが管轄区域で法的に実行可能。**

閉じた企業システムでは、経済はよりシンプルな割り当て（マネージャーが作業を割り当て、メトリクスは内部）に道を譲る。経済の文献は主にオープンネットワークに適用される。

## 実装する

`code/main.py` は以下を実装する:

- `shapley(value_fn, agents)` — 小さなNのための列挙による正確なシャプレー計算。
- `second_price_auction(bids)` — 誠実なメカニズム; 勝者が第二最高価格を支払う。
- `Reputation` — 指数減衰とスラッシングを持つDIDに紐付けられたレピュテーション。
- デモ1: 3つのエージェントが協力し、正確なシャプレーがクレジットを帰属する。
- デモ2: 5つのエージェントがタスクスロットに入札する; 第二価格オークションが勝者 + 支払いを選ぶ。
- デモ3: 異質なレピュテーションを持つエージェントへの100ラウンドのタスク割り当て; レピュテーション重み付きルーティングがウォームアップ後にランダムを10〜20%上回る。

実行:

```
python3 code/main.py
```

期待される出力: 各エージェントのシャプレー値; 誠実入札均衡を示すオークション結果; ウォームアップ後にランダムより10〜20%品質向上を示すレップ重み付きルーティング。

## 使ってみる

`outputs/skill-economy-designer.md` は最小限のエージェント経済を設計する: アイデンティティ層の選択、クレジット帰属メカニズム、支払いメカニズム、レピュテーションルール。

## 成果物を出す

2026年にエージェント経済を運営する:

- **トークンではなくレピュテーションから始める。** レピュテーションは単独で実装が安価で価値がある; トークンは法的・経済的複雑さを加える。
- **報酬の前に検証する。** 独立した検証ステップなしでクレジットを分配しない。自己報告品質はシビルゲームを引き起こす。
- **シャプレーサンプリング、シャプレー正確ではない。** 100〜1000の順序をサンプリングする; 正確な列挙はスケールしない。
- **減衰係数とフロアレピュテーションを上限にする。** 無制限の減衰は正当な貢献者を消し; 遅すぎる減衰は古い高レピュテーションエージェントに報酬を与える。
- **メカニズムを敵対的に監査する。** ネットワークを開く前に赤チームシナリオを実行する。すべてのメカニズムにはゲーム理論がある; 穴を見つけたいのは攻撃者ではなく自分たちだ。

## 演習

1. `code/main.py` を実行する。シャプレー値が合計値に等しくなることを確認する（効率性公理）。価値関数を変更する; シャプレー割り当ては期待された方向に変化するか？
2. シャプレー*サンプリング*（K順序でのモンテカルロ）を実装する。KはどのくらいKが近似精度に影響するか？N=4の正確なものと比較する。
3. オークションの前に連立形成ステップを実装する: エージェントがチームにマージして単位として入札できる。どの連立が形成されるか？結果は個別入札よりパレート優越か？
4. Google Researchのメカニズム設計投稿を読む。違反した場合に誠実性を壊す1つの前提を特定する。その失敗モードはLLM設定でどのように見えるか？
5. AAMAS 2025 分散型LaMAS論文を読む。合成タスクで10エージェントのシャプレーステップを実装する。正確な計算はどのくらいの時間がかかるか？100回の引き出しでサンプリングはどのくらい近いか？

## キーワード

| 用語 | よく言われること | 実際の意味 |
|------|----------------|------------------------|
| DePIN | 「分散型物理インフラ」 | トークンインセンティブの計算/ストレージ/帯域幅。Bittensor、Akash、Render。 |
| DID | 「分散型識別子」 | ポータブルIDのためのW3C仕様。エージェントのレピュテーションはプラットフォームではなくDIDに紐付けられる。 |
| ERC-4337 | 「アカウント抽象化」 | エージェント支払いを可能にするガスを後援できるコントラクトアカウント。 |
| シャプレー値 | 「公平なクレジット帰属」 | 効率性、対称性、線形性、nullを満たす唯一の割り当て。 |
| 第二価格オークション | 「Vickreyオークション」 | 誠実なメカニズム: 勝者が第二最高入札価格を支払う。単調集約互換。 |
| レピュテーション資本 | 「蓄積品質スコア」 | 確認された貢献からのDIDに紐付けられたスコア; 時間とともに減衰する。 |
| エージェントDAO | 「エージェント + 人間がガバナンス」 | エージェント投票者を一流とするDAO、投票権はレピュテーションに紐付けられる。 |
| TAO / FET / GPUクレジット | 「トークン単位」 | Bittensor TAO、Fetch.ai FET、各種DePINトークン。 |
