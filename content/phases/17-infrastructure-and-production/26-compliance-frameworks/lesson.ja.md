# コンプライアンス — SOC 2、HIPAA、GDPR、PCI-DSS、EU AI法、ISO 42001

> マルチフレームワークカバレッジは2026年のエンタープライズ案件のテーブルステークスだ。**EU AI法**：2024年8月1日に発効。ほとんどの高リスク要件は2026年8月2日に施行。違反時の罰金は高リスクシステムの義務（第99条(4)）で最大€1,500万または世界年間売上高の3%；禁止されたAI行為（第99条(3)）で最大€3,500万または7%。EUユーザーへのサービス提供の場合はグローバルに適用。**コロラド州AI法**：2026年6月30日施行（SB25B-004により2026年2月から延期）——高リスクシステムの影響評価、AI決定への異議申し立て権。バージニア州は信用/雇用/住宅/教育について同様。**SOC 2 Type II**：フィンテックのB2B AIの事実上の要件（Type Iではなく）。**GDPR**：最大の文書化されたAI固有の罰金はClearview AIに対する€3,050万（オランダ当局、2024年9月）；イタリアのGaranteが2024年12月にOpenAIに€1,500万（2026年3月の上訴で後に覆された）。推論時のリアルタイムPII除去が防御可能な標準；事後処理によるクリーンアップは不十分。**HIPAA**：医療従事者——BAAなしに外部AIサービスにPHIを送れない。**PCI-DSS**：AI相互作用層のカバレッジには自動ではなく設定＋契約上の合意が必要。**ISO 42001**：新興のAIガバナンス標準、ISO 27001と並んで調達要件として成長中。参照プロファイル：OpenAIはSOC 2 Type 2、ISO/IEC 27001:2022、ISO/IEC 27701:2019、GDPR/CCPA/HIPAA（BAA）/FERPA、ChatGPTの支払いコンポーネントにはPCI-DSSを維持している。クロスフレームワークマッピングで監査疲労を軽減：アクセスコントロールはISO 27001 A.5.15-5.18、GDPR第32条、HIPAA §164.312(a)にわたってマッピングできる。


## 学習目標

- LLM製品に関連する2026年の7つのフレームワークを列挙し、それぞれを顧客セグメントにマッチさせる。
- EU AI法の施行タイムライン（2024年8月に発効；高リスク施行は2026年8月）と2層の罰金上限（高リスク義務に€1,500万/3%、禁止行為に€3,500万/7%）を引用する。
- GDPR向けに事後処理によるPII除去が不十分な理由を説明し、リアルタイム推論層での除去を防御可能な標準として挙げる。
- クロスフレームワークコントロールマッピングを説明する（例：アクセスコントロールがISO 27001 A.5.15-5.18＋GDPR第32条＋HIPAA §164.312(a)にマッピングされる）。

## 問題の背景

エンタープライズ顧客の調達がSOC 2 Type II、GDPR、HIPAA BAA、ISO 27001、「EU AI法コンプライアンス声明」を求めてくる。チームはSOC 2 Type Iを持っている。Type IIまで6ヶ月でGDPR第30条の記録はまだ始めていない。

マルチフレームワークカバレッジはLLMの問題ではなく——LLM固有のオーバーレイを持つエンタープライズSaaSの問題だ。2026年の調達チームはPDFではなくフレームワークごとの行とコントロールごとの列を持つマトリクスを求める。

## コンセプト

### 7つのフレームワーク

| フレームワーク | スコープ | LLM固有の要件 |
|--------------|-------|----------------|
| SOC 2 Type II | B2B SaaSのベースライン | 6〜12ヶ月にわたって監査されるプロセスコントロール |
| HIPAA | 米国医療 | BAA必須；署名された合意なしにPHIをインフラの外に出せない |
| GDPR | EUユーザー | リアルタイムPII除去；データ主体の権利；第30条記録 |
| PCI-DSS | 支払いデータ | AIが支払いに触れる場合の設定＋契約 |
| EU AI法 | EUユーザーへのサービス | リスクティア分類；高リスクシステム：適合性評価、文書化、ログ |
| コロラド州AI法 | CO居住者へのサービス | 影響評価；異議申し立て権 |
| ISO 42001 | AIガバナンス | 新興；ISO 27001と並ぶ |

### EU AI法のタイムライン

- 2024年8月1日：発効。
- 2025年2月2日：禁止されたAI行為が施行。
- 2026年8月2日：高リスクシステムが施行（適合性評価、文書化、ログ）。
- 2027年8月：調和した法律の下の製品における高リスクシステム。

リスクティア：許容不可（禁止）、高リスク（適合性＋ログ）、限定リスク（透明性）、最小リスク（制約なし）。ほとんどのB2B LLM SaaSは限定リスク；高リスクは雇用、信用、教育、法執行、移民、必須サービスに適用。

罰金（第99条）：高リスクシステムの義務違反（第99条(4)）で最大€1,500万または世界年間売上高の3%；禁止されたAI行為（第99条(3)）で最大€3,500万または7%；より高い方が適用される。

### GDPR — リアルタイム除去が標準だ

事後処理クリーンアップ（LLMが見た後にPIIを除去する）は防御可能なポスチャーではない——モデルはすでにデータを見た。リアルタイム推論層での除去が2026年の標準だ：

- LLM呼び出し前のエンティティ認識。
- 一貫したトークン化（Meshアプローチ）でセマンティクスを保持。
- 除去されたプロンプトのみを保存＋同意済みのオプトインによる生データ。

最近の施行：Clearview AIに対する€3,050万（オランダ当局、2024年9月）は文書化された最大のAI固有のGDPR罰金；OpenAIに対する€1,500万（イタリアのGarante、2024年12月）は最大のLLM固有の罰金だが2026年3月の上訴で覆されさらなる審査が続いている。事後処理の主張は監査で失敗している。

### HIPAA — BAAは必須

署名された業務提携契約なしに外部AIサービスにPHIを送ることはできない。3つのハイパースケーラーLLMプラットフォーム（Bedrock、Azure OpenAI、Vertex）はBAAを提供している。OpenAIのダイレクトAPIはBAAを提供している。AnthropicのダイレクトAPIはBAAを提供している。PHIを送る前に確認すること。

### SOC 2 Type II

Type I：コントロールが設計され文書化されている。
Type II：コントロールが6〜12ヶ月にわたって効果的に運用されている。

2026年のB2B調達はデフォルトでType IIを求める。Type Iはスターターで；Type IIがゲートだ。

一般的な監査ドライバー：アクセスログ（誰が何を見たか）、変更管理（どのようにデプロイされたか）、リスク評価（四半期ごと）、インシデント対応（テスト済み？）。フェーズ17・25の監査ログが直接再利用できる。

### クロスフレームワークマッピング

1つのアクセスコントロールポリシーが複数のフレームワークコントロールを満たす：

| コントロール | フレームワーク |
|------------|---------------|
| アクセスログ | ISO 27001 A.5.15-5.18、GDPR第32条、HIPAA §164.312(a) |
| 変更管理 | ISO 27001 A.8.32、PCI DSS要件6、HIPAA違反通知スコープ |
| 転送中の暗号化 | ISO 27001 A.8.24、GDPR第32条、HIPAA §164.312(e) |
| シークレット管理 | ISO 27001 A.8.19、PCI DSS要件8、SOC 2 CC6.1 |

コンプライアンスツール（Drata、Vanta、Secureframe）がこのマッピングを自動化する。スケール時にはコストに見合う価値がある。

### ISO 42001 — 新興

2023年末に公開。ISO 27001と並んで調達要件として成長中。AIガバナンスのフレームワーク（リスク管理、データ品質、透明性、人間による監督を含む）。

### OpenAIの参照プロファイル

OpenAIはSOC 2 Type 2、ISO/IEC 27001:2022、ISO/IEC 27701:2019、GDPR/CCPA/HIPAA（BAA）/FERPA、ChatGPTの支払いコンポーネントにはPCI-DSSを維持している。これが概ね2026年のエンタープライズのテーブルステークスだ。

### 覚えておくべき数値

- EU AI法の罰金：高リスクシステムの義務（第99条(4)）で最大€1,500万/3%；禁止されたAI行為（第99条(3)）で最大€3,500万/7%。
- EU AI法の高リスク施行：2026年8月2日。
- 文書化された最大のAI固有のGDPR罰金：€3,050万、Clearview AI（オランダ当局、2024年9月）。
- 最大のLLM固有のGDPR罰金：€1,500万、OpenAI（イタリアのGarante、2024年12月；2026年3月の上訴で覆された）。
- SOC 2 Type IIウィンドウ：6〜12ヶ月のコントロール運用。
- コロラド州AI法施行日：2026年6月30日（SB25B-004により2026年2月から延期）。

## 使ってみる

`code/main.py`はPythonのコンプライアンスマッピングスプレッドシート——コントロールを入力すると、それが満たすフレームワークをリストアップする。

## 演習

1. 最初のエンタープライズ顧客がSOC 2 Type II、HIPAA BAA、EU AI法声明を必要とする。取引を成立させるための最小限の実行可能なコンプライアンスポスチャーは何か？
2. EU AI法のリスクティアの下で3つの仮想LLM製品を分類する。高リスクでは何が変わるか？
3. BAAなしにプロバイダーにPHIを誤って送ってしまった。インシデント対応を説明する。
4. ISO 42001が「2026年の中規模AIベンダーにとって必要かどうか」を議論する。
5. LLM監査ログフィールド（フェーズ17・25）を少なくとも3つのフレームワークコントロールにマッピングする。
