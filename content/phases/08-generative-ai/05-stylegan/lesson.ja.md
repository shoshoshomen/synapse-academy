# StyleGAN

> ほとんどのジェネレータは同時にすべての層に `z` を混ぜ込む。StyleGANはそれを分割した：まず `z` を中間 `w` にマッピングし、次にAdaINを通じて各解像度レベルで `w` を*注入*する。この単一の変更が潜在空間を解きほぐし、フォトリアリスティックな顔を7年間にわたって解決済みの問題にした。


## 問題

DCGANは `z` を転置畳み込みのスタックで画像にマッピングする。問題は `z` がポーズ、照明、アイデンティティ、背景——すべてを絡み合って制御することだ。`z` の1つの軸を動かすと4つ全部が変わる。表現がそのようには分解されていないため、モデルに「同じ人、異なるポーズ」と聞くことができない。

Karras et al.（2019、NVIDIA）が提案したのは：`z` を直接畳み込み層に与えるのをやめること。定数 `4×4×512` テンソルをネットワーク入力として与える。`z ∈ Z → w ∈ W` をマッピングする8層MLPを学習する。各解像度で *適応インスタンス正規化*（AdaIN）を通じて `w` を注入する：各畳み込み特徴マップを正規化し、`w` のアフィン投影でスケールとシフトする。確率的な詳細（肌の毛穴、毛髪）のために層ごとのノイズを追加する。

結果：`W` は「高レベルスタイル」（ポーズ、アイデンティティ）と「細かいスタイル」（照明、色）に対してほぼ直交した軸を持つ。低解像度レベルに画像Aの `w` を、高解像度レベルに画像Bの `w` を使うことで、2つの画像間でスタイルを交換できる。これにより編集、クロスドメインのスタイライズ化、そして「StyleGANインバージョン」研究の系統全体が解放された。

## 概念

![StyleGAN：マッピングネットワーク＋AdaIN＋層ごとのノイズ](../assets/stylegan.svg)

**マッピングネットワーク。** `f: Z → W`、8層MLP。`Z = N(0, I)^512`。`W` はガウス分布に強制されない——データ適応型の形状を学習する。

**シンセシスネットワーク。** 学習済み定数 `4×4×512` から始まる。各解像度ブロック：`アップサンプル → 畳み込み → AdaIN(w_i) → ノイズ → 畳み込み → AdaIN(w_i) → ノイズ`。解像度は倍増：4、8、16、32、64、128、256、512、1024。

**AdaIN。**

```
AdaIN(x, y) = y_scale · (x - mean(x)) / std(x) + y_bias
```

ここで `y_scale` と `y_bias` は `w` のアフィン投影から来る。特徴マップごとに正規化し、再スタイライズする。ここでの「スタイル」は特徴マップの1次および2次統計だ。

**層ごとのノイズ。** 各特徴マップに追加される単一チャンネルのガウスノイズ、学習済みチャンネルごとの係数でスケーリングされる。グローバル構造に影響を与えずに確率的な詳細を制御する。

**トランケーショントリック。** 推論時、`z` をサンプリングし `w = mapping(z)` を計算し、`w' = ŵ + ψ·(w - ŵ)` とする（ここで `ŵ` は多くのサンプルの平均 `w`）。`ψ < 1` は多様性と品質をトレードする。ほぼすべてのStyleGANデモは `ψ ≈ 0.7` を使っている。

## StyleGAN 1 → 2 → 3

| バージョン | 年 | イノベーション |
|---------|------|------------|
| StyleGAN | 2019 | マッピングネットワーク＋AdaIN＋ノイズ＋プログレッシブ成長。 |
| StyleGAN2 | 2020 | ウェイトデモジュレーションがAdaINを置き換える（液滴アーティファクトを修正）；スキップ/残差アーキテクチャ；パス長正則化。 |
| StyleGAN3 | 2021 | エイリアスフリー畳み込み＋等変カーネル；テクスチャのピクセルグリッドへの固着を排除。 |
| StyleGAN-XL | 2022 | クラス条件付き、1024²、ImageNet。 |
| R3GAN | 2024 | より強い正則化でリブランド；FFHQ-1024でパラメータ20倍少なく拡散に差を縮める。 |

2026年においてStyleGAN3は依然として次のデフォルトだ：(a) 高FPSでの狭いドメインのフォトリアリズム、(b) 少数ショットのドメイン適応（新しいデータセットで100枚の画像で訓練し、マッピングを凍結）、(c) インバージョンベースの編集（本物の写真を再構成する `w` を見つけ、その `w` を編集する）。オープンドメインのテキスト→画像では適切なツールではない——拡散が適している。

## 実装する

`code/main.py` は1次元の「StyleGAN Lite」のおもちゃを実装する：マッピングMLP、学習済み定数ベクトルを取り `w` 由来のスケール/バイアスでそれを変調するシンセシス関数、層ごとのノイズ。ジェネレータの入力に `z` を連結するよりも、`w` をアフィン変調で注入する方が優れているか同等であることを示す。

### ステップ1：マッピングネットワーク

```python
def mapping(z, M):
    h = z
    for i in range(num_layers):
        h = leaky_relu(add(matmul(M[f"W{i}"], h), M[f"b{i}"]))
    return h
```

### ステップ2：適応インスタンス正規化

```python
def adain(x, w_scale, w_bias):
    mu = mean(x)
    sd = std(x)
    x_norm = [(xi - mu) / (sd + 1e-8) for xi in x]
    return [w_scale * xi + w_bias for xi in x_norm]
```

特徴マップごとのスケールとバイアスは線形投影を通じて `w` から来る。

### ステップ3：層ごとのノイズ

```python
def add_noise(x, sigma, rng):
    return [xi + sigma * rng.gauss(0, 1) for xi in x]
```

チャンネルごとのシグマは学習可能。

## 落とし穴

- **液滴アーティファクト。** StyleGAN 1ではAdaINが平均をゼロにするため、特徴マップに塊状の液滴が生成された。StyleGAN 2のウェイトデモジュレーションは、代わりに畳み込みウェイトをスケーリングすることでこれを修正する。
- **テクスチャの固着。** StyleGAN 1と2のテクスチャはオブジェクト座標ではなくピクセル座標を追跡した（補間時に見える）。StyleGAN 3のエイリアスフリー畳み込みはウィンドウ付きsincフィルタでこれを修正する。
- **モードカバレッジ。** トランケーション `ψ < 0.7` は綺麗に見えるが、狭いコーンからサンプリングする；多様性が必要なら `ψ = 1.0` を使う。
- **インバージョンは損失がある。** 本物の写真を `W` に逆変換するには、通常最適化またはエンコーダ（e4e、ReStyle、HyperStyle）が使われる。多くのイテレーションで結果がドリフトする。

## 使ってみる

| ユースケース | アプローチ |
|----------|----------|
| フォトリアルな人間の顔（アニメ、製品、狭いドメイン） | StyleGAN3 FFHQ / カスタムファインチューン |
| 写真からの顔編集 | e4eインバージョン＋StyleSpace / InterFaceGANの方向 |
| 顔スワップ / リエナクトメント | StyleGAN＋エンコーダ＋ブレンディング |
| アバターパイプライン | 少データファインチューン用のADA付きStyleGAN3 |
| 少数の画像からのドメイン適応 | マッピングネットワークを凍結し、シンセシスをファインチューン |
| マルチモーダルまたはテキスト条件付き生成 | やめろ——拡散を使え |

解答が「人の顔の写真」であるプロダクション品質のデモでは、StyleGANは推論コスト（単一フォワードパス、4090で<10ms）と同じ品質基準でのシャープさで拡散を上回る。

## 成果物を出す

`outputs/skill-stylegan-inversion.md` を保存する。スキルは本物の写真を受け取り、インバージョン手法（e4e / ReStyle / HyperStyle）、期待潜在損失、編集予算（アーティファクト前に `W` でどれだけ移動できるか）、既知の良い編集方向（年齢、表情、ポーズ）のリストを出力する。

## 演習

1. **易。** `code/main.py` を `adain_on=True` と `adain_on=False` で実行する。固定潜在変数対摂動潜在変数の出力の広がりを比較する。
2. **中。** ミキシング正則化を実装する：訓練バッチで `w_a`、`w_b` を計算し、シンセシスの前半に `w_a`、後半に `w_b` を適用する。デコーダはディスエンタングルされたスタイルを学習するか？
3. **難。** 事前学習済みStyleGAN3 FFHQモデル（ffhq-1024.pkl）を使う。ラベル付きサンプルでSVMを訓練することで「笑顔」を制御する `w` の方向を見つける；アイデンティティがドリフトし始めるまでどれだけ押せるかを報告する。

## キーワード

| 用語 | 一般的な言い方 | 実際の意味 |
|------|-----------------|-----------------------|
| マッピングネットワーク | 「MLP」 | `f: Z → W`、8層、潜在幾何学をデータ統計から切り離す。 |
| W空間 | 「スタイル空間」 | マッピングネットワークの出力；ほぼディスエンタングル。 |
| AdaIN | 「適応インスタンス正規化」 | 特徴マップを正規化し、`w` 投影でスケール＋シフト。 |
| トランケーショントリック | 「Psi」 | `w = mean + ψ·(w - mean)`、ψ<1で多様性と品質をトレード。 |
| パス長正則化 | 「PL正則化」 | `w` の単位変化あたりの画像の大きな変化にペナルティ；`W` をよりスムーズにする。 |
| ウェイトデモジュレーション | 「StyleGAN2の修正」 | 活性化の代わりに畳み込みウェイトを正規化；液滴アーティファクトを消す。 |
| エイリアスフリー | 「StyleGAN3のトリック」 | ウィンドウ付きsincフィルタ；テクスチャのピクセルグリッドへの固着を排除。 |
| インバージョン | 「本物の画像のwを見つける」 | `G(w) ≈ x` になるよう `x → w` を最適化またはエンコード。 |

## プロダクションノート：StyleGANが2026年においても出荷される理由

StyleGAN3は4090で10ms未満で1024²のFFHQ顔を生成する——`num_steps = 1`、VAEデコードなし、クロスアテンションパスなし。プロダクション用語ではこれが任意の画像ジェネレータの最低レイテンシだ。同じ解像度での50ステップSDXL + VAEデコードパイプラインは約3秒。**300倍の差**であり、狭いドメインの製品（アバターサービス、IDドキュメントパイプライン、ストック顔生成）ではTCOで勝つ。

2つの運用上の結果：

- **スケジューラなし、バッチャーなし。** 目標占有率での静的バッチが最適だ。連続バッチング（LLMと拡散には必須）はすべてのリクエストが同じFLOPsを取るためゼロの利益を提供する。
- **トランケーション `ψ` が安全ノブだ。** `ψ < 0.7` はマッピングネットワークの範囲の狭いコーンからサンプリングする。これがサービング層のサンプル分散に対する唯一のレバーだ。ピーク負荷では低い `ψ`、プレミアムユーザーには高い `ψ`。
