# 条件付きGANとPix2Pix

> 2014〜2017年の最初の大きな解放は、GANが作るものを制御することだった。ラベルを付ける、あるいは画像を、文章を。Pix2Pixは画像バージョンを実装し、狭い画像間タスクでは今でもすべての汎用テキスト→画像モデルを上回っている。


## 問題

無条件GANは任意の顔をサンプリングする。デモには使えるが、プロダクションでは無用だ。欲しいのは：*スケッチを写真に変換*、*地図を航空写真に変換*、*日中のシーンを夜景に変換*、*グレースケール画像を着色*。これらすべてにおいて、入力画像 `x` が与えられ、意味的な対応を持つ `y` を出力しなければならない。`x` ごとに多くの妥当な `y` がある。平均二乗誤差はそれらを泥状に平坦化する。敵対的損失はそうならない。「本物らしく見える」は鋭いからだ。

条件付きGAN（Mirza & Osindero、2014）は条件 `c` を `G` と `D` 両方への入力として追加する。Pix2Pix（Isola et al.、2017）はこれを専門化した：条件は完全な入力画像、ジェネレータはU-Net、ディスクリミネータは*パッチベース*の分類器（PatchGAN）、損失は敵対的＋L1だ。このレシピは、*ペアデータ*で訓練されるため、2026年においても狭い画像間ドメインで一から作ったテキスト→画像モデルを上回る——必要なシグナルが正確に手元にある。

## 概念

![Pix2Pix：U-Netジェネレータ、PatchGANディスクリミネータ](../assets/pix2pix.svg)

**条件付きG。** `G(x, z) → y`。Pix2Pixでは `z` はG内のドロップアウト（入力ノイズなし——Isolaはexplicitなノイズが無視されることを発見した）。

**条件付きD。** `D(x, y) → [0, 1]`。入力は*ペア*（条件、出力）だ。これが重要な違いだ：Dは `y` が `x` と一致しているかを判断しなければならない。単に `y` が本物らしく見えるかだけでなく。

**U-Netジェネレータ。** ボトルネックをまたいだスキップ接続を持つエンコーダ・デコーダ。入力と出力が低レベルの構造（エッジ、シルエット）を共有するタスクに重要。スキップなしでは高周波数の詳細が消える。

**PatchGANディスクリミネータ。** 単一の本物/偽物スコアを出力する代わりに、Dは各セルが約70×70ピクセルの受容野を判断する `N×N` グリッドを出力する。平均化する。これはマルコフ確率場の仮定：リアリティはローカルだ。訓練が速く、パラメータが少なく、より鮮明な出力。

**損失。**

```
loss_G = -log D(x, G(x)) + λ · ||y - G(x)||_1
loss_D = -log D(x, y) - log (1 - D(x, G(x)))
```

L1項が訓練を安定化し、Gを既知の目標に向かって押す。L1はL2よりシャープなエッジを与える（中央値、平均でなく）。`λ = 100` がPix2Pixのデフォルトだった。

## CycleGAN — ペアがないとき

Pix2Pixはペアの `(x, y)` データを必要とする。CycleGAN（Zhu et al.、2017）はサイクル整合性損失という追加コストを払ってこの要件を省く：2つのジェネレータ `G: X → Y` と `F: Y → X`。`F(G(x)) ≈ x` かつ `G(F(y)) ≈ y` になるよう訓練する。これにより、ペアの例なしで馬をシマウマに、夏を冬に変換できる。

2026年においてペアなし画像間変換は主にControlNet、IP-Adapter経由の拡散で行われる。しかし、サイクル整合性のアイデアはほぼすべてのペアなしドメイン適応論文に生き残っている。

## 実装する

`code/main.py` は1次元データ上で小さな条件付きGANを実装する。条件 `c` はクラスラベル（0または1）だ。タスク：与えられたクラスの条件付き分布からサンプルを生成する。

### ステップ1：条件をGとDの両方の入力に追加する

```python
def G(z, c, params):
    return mlp(concat([z, one_hot(c)]), params)

def D(x, c, params):
    return mlp(concat([x, one_hot(c)]), params)
```

ワンホットエンコーディングが最もシンプルな方法だ。大きなモデルは学習済み埋め込み、FiLMモジュレーション、またはクロスアテンションを使う。

### ステップ2：条件付きで訓練する

```python
for step in range(steps):
    x, c = sample_real_conditional()
    noise = sample_noise()
    update_D(x_real=x, x_fake=G(noise, c), c=c)
    update_G(noise, c)
```

ジェネレータは周辺分布ではなく、*与えられた条件*に対する本物の分布にマッチしなければならない。

### ステップ3：クラスごとの出力を検証する

```python
for c in [0, 1]:
    samples = [G(noise, c) for noise in batch]
    mean_c = mean(samples)
    assert_near(mean_c, real_mean_for_class_c)
```

## 落とし穴

- **条件が無視される。** GはDが条件シグナルが弱くてペナルティを与えないため、周辺化を学習する。修正：Dにより積極的に条件付け（後期レイヤーだけでなく早期レイヤー）、プロジェクションディスクリミネータを使う（Miyato & Koyama 2018）。
- **L1の重みが低すぎる。** Gは忠実でない任意の本物らしい出力に流れる。Pix2Pixスタイルのタスクにはλ≈100から始める。
- **L1の重みが高すぎる。** GはL1がまだL_pノルムなのでぼやけた出力を生成する。訓練が安定したらランプダウンする。
- **DへのグラウンドトゥルースリーケージIO。** D入力として `(x, y)` を結合する（`y` だけでなく）。これなしではDは整合性を確認できない。
- **クラスごとのモード崩壊。** 各クラスが独立して崩壊できる。クラス条件付きの多様性チェックを実行する。

## 使ってみる

2026年の画像間タスクの状況：

| タスク | 最適アプローチ |
|------|---------------|
| スケッチ→写真、同ドメイン、ペアデータあり | Pix2Pix / Pix2PixHD（依然として速くシャープ） |
| スケッチ→写真、ペアなし | スクリブル条件付けモデルのControlNet |
| セマンティックセグ→写真 | SPADE / GauGAN2またはSD + ControlNet-Seg |
| スタイル変換 | IP-AdapterまたはLoRAを使った拡散；GANの方法はレガシー |
| 深度→写真 | Stable DiffusionのControlNet-Depth |
| 超解像度 | Real-ESRGAN（GAN）、ESRGAN-Plus、またはSD-Upscale（拡散） |
| 着色 | ColTran、拡散ベースの着色器、またはPix2Pix-color |
| 日中→夜景、季節、天気 | CycleGANまたはControlNetベース |

Pix2Pixが適切なのは、(a) 数千のペアの例がある、(b) タスクが狭くて繰り返し可能、(c) 高速な推論が必要、の場合だ。汎用オープンドメインタスクでは拡散が勝つ。

## 成果物を出す

`outputs/skill-img2img-chooser.md` を保存する。スキルはタスクの説明、データの可用性（ペアあり対なし、サンプル数N）、レイテンシ/品質予算を受け取り、アプローチ（Pix2Pix、CycleGAN、ControlNetバリアント、SDXL + IP-Adapter）、訓練データ要件、推論コスト、評価プロトコル（LPIPS、FID、タスク固有）を出力する。

## 演習

1. **易。** `code/main.py` を修正して3つ目のクラスを追加する。Gが依然として各クラスのノイズを正しいモードにマッピングすることを確認する。
2. **中。** 1次元設定でL1を知覚スタイル損失（たとえば特徴抽出器として機能する小さな凍結されたD）に置き換える。条件付き分布の鮮明さは変わるか？
3. **難。** 1次元設定でCycleGANをスケッチする：2つの分布、2つのジェネレータ、サイクル損失。ペアデータなしで間の変換を学習することを示す。

## キーワード

| 用語 | 一般的な言い方 | 実際の意味 |
|------|-----------------|-----------------------|
| 条件付きGAN | 「ラベル付きGAN」 | G(z, c)、D(x, c)。両方のネットワークが条件を見る。 |
| Pix2Pix | 「画像間GAN」 | U-Net G と PatchGAN D + L1損失を使ったペアcGAN。 |
| U-Net | 「スキップ付きエンコーダ・デコーダ」 | 対称畳み込みネットワーク；スキップが高周波数を保持。 |
| PatchGAN | 「ローカルリアリティ分類器」 | Dがグローバルスコアの代わりにパッチごとのスコアを出力。 |
| CycleGAN | 「ペアなし画像変換」 | 2つのG ＋ サイクル整合性損失；ペアデータ不要。 |
| SPADE | 「GauGAN」 | セマンティックマップで中間活性化を正規化；セグメンテーション→画像。 |
| FiLM | 「特徴ごとの線形変調」 | 条件からの特徴ごとのアフィン変換；安価な条件付け。 |

## プロダクションノート：Pix2Pixをレイテンシ境界ベースラインとして

ペアデータと狭いタスク（スケッチ→レンダリング、セマンティックマップ→写真、日→夜）がある場合、Pix2Pixのワンショット推論は拡散を桁違いにレイテンシで上回る。プロダクション比較は通常：

| パス | ステップ | 単一L4での512²の典型的なレイテンシ |
|------|-------|----------------------------------------|
| Pix2Pix（U-Netフォワード） | 1 | 約30ms |
| SD-Inpaint または SD-Img2Img | 20 | 約1.2秒 |
| SDXL-Turbo Img2Img | 1〜4 | 約0.15〜0.35秒 |
| ControlNet + SDXLベース | 20〜30 | 約3〜5秒 |

Pix2Pixは静的バッチのスループットで勝つ（すべてのリクエストが同じFLOPs）。拡散は品質と汎化で勝つ。現代のアプローチは多くの場合、狭いタスク用のPix2Pixスタイルの蒸留モデルをデプロイし、テール入力には拡散フォールバックを使うことだ。
