# 視覚的自己回帰モデリング（VAR）：次スケール予測

> 拡散モデルは時間方向に反復的にサンプリングする（デノイズのステップ）。VARはスケール方向に反復的にサンプリングする——1×1トークンを予測し、次に2×2、4×4、最終解像度まで、各スケールが前のスケールを条件として使う。2024年の論文はVARが画像生成でGPTスタイルのスケーリング則を満たし、同じ計算コストでDiTを超えることを示した。このレッスンではコアメカニズムを構築する。


## 問題

自己回帰的生成は言語モデリングを支配してきた。なぜなら予測可能にスケールするからだ：より多くの計算、より多くのパラメータ、より低いパープレキシティ、より良い出力。2024年以前に画像生成で2つの主なARの試みがあった：PixelRNN/PixelCNN（ピクセル単位）とDALL-E 1 / Parti / MuseGAN（VQ-VAEコード上のトークン単位）。

どちらも生成順序問題に悩まされた。ピクセルとトークンは2Dグリッドに配置されているが、ARモデルは1Dのラスター順に訪問しなければならない。初期のコーナーピクセルは画像が最終的にどうなるか全くわからない。生成品質は同じ計算量のGPT-on-textよりスケールが悪く、同じ計算量の拡散モデル品質には到達しなかった。

VARは生成されるものを変えることで生成順序問題を修正する。空間でイメージトークンを1つずつ予測する代わりに、VARは解像度を上げながら画像全体を予測する。ステップ1：1×1トークンを予測する（画像の全体的な「要約」）。ステップ2：2×2トークングリッドを予測する（粗い特徴）。ステップ3：4×4グリッド。ステップK：最終的な (H/8)×(W/8) グリッド。

各スケールは（「スケール順序」で因果的に）すべての前のスケールに注意を向け、自スケール内では並列だ。順序問題は消える：スケールkでの画像全体が1回のトランスフォーマーパスで生成される。

## 概念

### マルチスケールVQトークナイザー

VARには**マルチスケール離散トークナイザー**が必要だ。画像xに対して、漸進的に高解像度のトークングリッドのシーケンスを生成する：

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

各 z_k は同じコードブック（典型的なサイズ 4096〜16384）を使う。各スケールでのトークン化は独立でない——各スケールの残差を合算するとfを再構成するよう訓練される：

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

これは**残差VQ**の変形だ。スケールkはスケール1..k-1が見逃したものをキャプチャする。デコーダーはすべてのスケール埋め込みの合計を取り、画像を生成する。

マルチスケールVQトークナイザーは（VQGANと同様に）一度訓練されてから凍結される。すべての生成作業はその上の自己回帰モデルによって行われる。

### 次スケール予測

生成モデルはすべての前のスケールのトークンを見て、次のスケールのトークンを予測するトランスフォーマーだ。

入力シーケンス構造：
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

位置埋め込みはスケールインデックスとスケール内の空間位置の両方をエンコードする。注意はスケール順序で因果的：スケールk、位置(i, j)のトークンはスケール1..kのすべてのトークンと、使用される任意のイントラスケール順序でそれより前のスケールkのトークンに注意を向けられる（VARは固定の位置的注意を使い、イントラスケール因果性なし——スケール内のすべての位置は並列に予測される）。

訓練損失：各スケールkで、すべての前スケールトークンが与えられてトークン z_k を予測する。離散VQコードのクロスエントロピー損失。GPTと同じ構造だが「シーケンス」がスケール構造になっている。

### 生成

推論時：
```
generate z_1 = sample from p(z_1)                    # 1トークン
generate z_2 = sample from p(z_2 | z_1)              # 4トークンを並列
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16トークンを並列
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

K = 10スケールの場合、生成は10回のトランスフォーマーフォワードパスだ。各パスはスケール全体を並列に生成する——スケール内のトークン単位の自己回帰はない。256×256の画像では、DiTの28〜50ステップに対してこれは約10パスだ。

### 次スケールが次トークンに勝る理由

3つの構造的な優位性：
1. **粗から細への流れが自然な画像統計に沿う。** 人間の視覚知覚と画像データセットはどちらもスケール依存の規則性を示す：低周波の構造は安定で予測可能；高周波の詳細は低周波の内容に条件付けられる。次スケール予測はこれを活用する。
2. **スケール内の並列生成。** GPTスタイルのトークンARとは異なり、VARは1ステップでスケールのすべてのトークンを生成する。有効生成長は線形ではなく対数スケールだ。
3. **生成順序バイアスなし。** スケールkのトークンはスケールk-1のすべてを見る；遅い文脈が利用可能になる前に早いトークンがコミットするよう強いる「左側」や「上側」のバイアスがない。

### スケーリング則

Tian et al. はVARがImageNetのFIDでGPTがパープレキシティでするように——べき乗スケーリング曲線に従うことを実証した。パラメータや計算量を倍にすると確実にエラーが半分になる。これが計算量から予測可能なスケール予測をもたらす最初の画像生成モデルだった——アーキテクチャごとの実験的な推測ではなく。結果として、VAR スケールの予測は計算量から予測可能になり、アーキテクチャごとの経験的推測にならない。

### 拡散との関係

VARと拡散は同じデータ圧縮の話を共有する：どちらも生成問題を一連の簡単なサブ問題に分解する。

- 拡散：徐々にノイズを加え、1ステップを元に戻すことを学ぶ。
- VAR：徐々に解像度を上げ、次のスケールを予測することを学ぶ。

これらは問題に対する異なる軸だ。どちらも扱いやすい条件付き分布を生む。経験的にVARは推論が速い（より少ないパス、スケール内はすべて並列）し、クラス条件付きImageNetでDiTに匹敵するか上回る。テキスト条件付きVAR（VARclip、HART）は活発な研究方向だ。

## 実装する

`code/main.py` では：
1. 合成「画像」データ（2Dガウシアンリング）上に小さな**マルチスケールVQトークナイザー**を構築する。
2. トークンを次スケール予測する**VARスタイルのトランスフォーマー**を訓練する。
3. トランスフォーマーを4回呼んで（4スケール）サンプリングし、デコードする。
4. スケール順序の訓練がスケール内の生成を並列にすることを確認する。

これはおもちゃの実装だ。ポイントはスケール構造の注意マスクと並列スケール内生成が実際に機能することを見ることだ。

## 演習

1. **スケール数のアブレーション。** 4、6、8、10スケールでVARを訓練する。自己回帰パス数に対する再構成品質を測る。より多くのスケール = より細かい残差 = より良い品質だがより多くのパス。

2. **コードブックサイズ。** コードブックサイズ512、4096、16384でトークナイザーを訓練する。大きなコードブックはより良い再構成を与えるが予測が難しくなる。ニーポイントを見つける。

3. **スケール内並列性のチェック。** 訓練済みVARに対して注意パターンを明示的に測定する。スケールk内で、モデルはクロススケール位置には注意するがイントラスケールには注意しないか？マスクの実装を確認する。

4. **VAR対DiTのスケーリング。** 同じImageNetクラス条件付きタスクで、マッチしたパラメータバジェット（例：33M、130M、458M）でVARとDiTを訓練する。計算量対FIDをプロットする。各サイズでVARがDiTを上回るはず——論文の結果を小規模で再現する。

5. **テキスト条件付け。** VARをadaLN経由の追加条件付け入力としてテキスト埋め込み（CLIPプール）を取るよう拡張する。これはHARTのレシピだ。テキスト整合サンプリングでFIDはどれだけ改善するか？

## キーワード

| 用語 | 一般的な言い方 | 実際の意味 |
|------|----------------|----------------------|
| VAR | 「Visual AutoRegressive」 | VQトークングリッドのピラミッドにおける次スケール予測による画像生成 |
| 次スケール予測 | 「粗を予測し、次に細を」 | モデルが前のすべてのスケールを条件として増加する解像度スケールでトークンを予測する |
| マルチスケールVQトークナイザー | 「残差VQ」 | 増加解像度のKトークングリッドを生成するVQ-VAE、デコーダーはすべてのスケールを合算する |
| スケールk | 「ピラミッドレベルk」 | K解像度レベルの1つ、k=1の1×1からk=Kの(H/p)×(W/p)まで |
| スケール内並列 | 「スケールごとに1フォワード」 | スケールkのすべてのトークンが1回のトランスフォーマーパスで予測される、自己回帰でなく |
| スケール間因果 | 「スケール順序アテンション」 | スケールkのトークンはスケール1..kのすべてに注意できるがk+1..Kには注意できない |
| 残差VQ | 「加算型トークン化」 | 各スケールのトークンは低いスケールに残った残差をエンコードする；デコーダーはすべてのスケール埋め込みを合算する |
| VARスケーリング則 | 「画像GPTスケーリング」 | FIDは言語モデルのパープレキシティのように計算量において予測可能なべき乗則に従う |
| HART | 「ハイブリッドVAR＋テキスト」 | MaskGITスタイルの反復デコーディングとVARのスケール構造を組み合わせたテキスト条件付きVAR変形 |
| スケール位置埋め込み | 「(スケール, 行, 列) トリプル」 | 位置エンコーディングはスケールインデックスとスケール内の空間座標の両方を持つ |
