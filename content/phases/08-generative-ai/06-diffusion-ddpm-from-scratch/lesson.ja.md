# 拡散モデル — DDPMをゼロから

> Ho、Jain、Abbeel（2020）はこの分野が手放せないレシピを与えた。1000回の小さなステップでデータをノイズで破壊する。ノイズを予測する1つのニューラルネットを訓練する。推論時にそのプロセスを逆転させる。今日、すべての主流の画像、動画、3D、音楽モデルがこのループの上で動き、場合によってはフローマッチングやConsistencyのトリックが上乗せされている。


## 問題

`p_data(x)` のサンプラーが欲しい。GANは頻繁に発散するミニマックスゲームをする。VAEはガウスデコーダからぼやけたサンプルを生成する。本当に欲しいのは、(a) 単一の安定した損失（サドルポイントなし、ミニマックスなし）、(b) `log p(x)` の下限（尤度が持てる）、(c) SOTAの品質にマッチするサンプル、を持つ訓練目的だ。

Sohl-Dickstein et al.（2015）が理論的な答えを持っていた：Gaussianノイズを徐々に加えるマルコフ連鎖 `q(x_t | x_{t-1})` を定義し、ノイズを除去する逆連鎖 `p_θ(x_{t-1} | x_t)` を訓練する。Ho、Jain、Abbeel（2020）は損失を1行に単純化できることを示し、数学を整理した。2020年にはこれは珍品だった。2021年に最先端のサンプルを生成した。2022年にStable Diffusionになった。2026年には基盤だ。

## 概念

![DDPM：フォワードノイズ、リバースデノイズ](../assets/ddpm.svg)

**フォワードプロセス `q`。** `T` 回の小さなステップでGaussianノイズを加える。数学が扱いやすい理由——累積ステップもGaussianだという閉形式：

```
q(x_t | x_0) = N( sqrt(α̅_t) · x_0,  (1 - α̅_t) · I )
```

ここで `α̅_t = ∏_{s=1..t} (1 - β_s)`（T=1000ステップにわたって線形に変化するスケジュール `β_t`）。`β_t` を1e-4から0.02まで線形に選ぶと `x_T` はほぼ `N(0, I)` になる。

**リバースプロセス `p_θ`。** 加えられたノイズを予測するニューラルネット `ε_θ(x_t, t)` を学習する。`x_t` が与えられたとき、次のようにノイズを除去する：

```
x_{t-1} = (1 / sqrt(α_t)) · ( x_t - (β_t / sqrt(1 - α̅_t)) · ε_θ(x_t, t) )  +  σ_t · z
```

ここで `σ_t` は `sqrt(β_t)` か学習済み分散のどちらかだ。この式は醜いが単なる代数だ——事後分布 `q(x_{t-1} | x_t, x_0)` について `x_{t-1}` を解き、`x_0` をノイズ予測推定値で置き換える。

**訓練損失。**

```
L_simple = E_{x_0, t, ε} [ || ε - ε_θ( sqrt(α̅_t) · x_0 + sqrt(1 - α̅_t) · ε,  t ) ||² ]
```

データから `x_0` をサンプリングし、ランダムな `t` を選び、`ε ~ N(0, I)` をサンプリングし、閉形式でノイジーな `x_t` を一気に計算し、ノイズを回帰する。1つの損失、ミニマックスなし、KLなし、再パラメータ化トリックなし。

**サンプリング。** `x_T ~ N(0, I)` から始める。`t = T` から `1` まで逆ステップを繰り返す。完了。

## なぜ機能するか

3つの直感：

1. **ノイズ除去は簡単；生成は難しい。** `t=T` ではデータは純粋なノイズ——ネットは些細な問題を解く。`t=0` ではネットは数ピクセルだけを整理すればいい。中間の `t` では問題は難しいが、ネットはすべてのノイズレベルから同じウェイトを通じて多くの勾配を受け取る。

2. **スコアマッチングに偽装されている。** Vincent（2011）は、ノイズを予測することが `∇_x log q(x_t | x_0)` の推定、つまり*スコア*を推定することと同等であることを証明した。逆SDEはこのスコアを使って密度勾配を上って高確率領域に向かって歩く——誘導されたランダムウォーク。

3. **ELBOは単純なMSEに還元される。** 完全な変分下限はタイムステップごとのKL項を持つ。DDPMのパラメータ化でそれらのKL項はノイズ予測の特定の係数付きMSEに単純化される；Hoはその係数を落とし（「単純な」損失と呼ぶ）、品質が*向上した*。

## 実装する

`code/main.py` は1次元DDPMを実装する。データは2モード混合だ。「ネット」は `(x_t, t)` を取り予測ノイズを出力する小さなMLPだ。訓練は1行の損失だ。サンプリングは逆連鎖を繰り返す。

### ステップ1：フォワードスケジュール（閉形式）

```python
betas = [1e-4 + (0.02 - 1e-4) * t / (T - 1) for t in range(T)]
alphas = [1 - b for b in betas]
alpha_bars = []
cum = 1.0
for a in alphas:
    cum *= a
    alpha_bars.append(cum)
```

### ステップ2：一気に `x_t` をサンプリング

```python
def forward_sample(x0, t, alpha_bars, rng):
    a_bar = alpha_bars[t]
    eps = rng.gauss(0, 1)
    x_t = math.sqrt(a_bar) * x0 + math.sqrt(1 - a_bar) * eps
    return x_t, eps
```

### ステップ3：1つの訓練ステップ

```python
def train_step(x0, model, alpha_bars, rng):
    t = rng.randrange(T)
    x_t, eps = forward_sample(x0, t, alpha_bars, rng)
    eps_hat = model_forward(model, x_t, t)
    loss = (eps - eps_hat) ** 2
    return loss, gradient_step(model, ...)
```

### ステップ4：逆サンプリング

```python
def sample(model, alpha_bars, T, rng):
    x = rng.gauss(0, 1)
    for t in range(T - 1, -1, -1):
        eps_hat = model_forward(model, x, t)
        beta_t = 1 - alphas[t]
        x = (x - beta_t / math.sqrt(1 - alpha_bars[t]) * eps_hat) / math.sqrt(alphas[t])
        if t > 0:
            x += math.sqrt(beta_t) * rng.gauss(0, 1)
    return x
```

40タイムステップと24ユニットのMLPを使った1次元問題では、約200エポックで2モード混合を学習する。

## 時間条件付け

ネットはどのタイムステップをデノイズしているかを知る必要がある。2つの標準オプション：

- **Sinusoidal埋め込み。** Transformerの位置エンコーディングのように。`embed(t) = [sin(t/ω_0), cos(t/ω_0), sin(t/ω_1), ...]`。MLPを通し、ネットにブロードキャストする。
- **FiLM / グループ正規化条件付け。** 埋め込みを各ブロックでチャンネルごとのスケール/バイアス（FiLM）に投影する。

おもちゃコードはsinusoidal → concatを使う。プロダクションのU-NetはFiLMを使う。

## 落とし穴

- **スケジュールが非常に重要。** 線形 `β` はDDPMのデフォルトだが、コサインスケジュール（Nichol & Dhariwal、2021）は同じ計算でより良いFIDを与える。品質が停滞したらスケジュールを切り替える。
- **タイムステップ埋め込みは脆弱。** 生の `t` を浮動小数点として渡すことは1次元のおもちゃには機能するが画像では失敗する；常に適切な埋め込みを使う。
- **V予測対ε予測。** 非常に小さいまたは大きい `t` では、`ε` は信号対ノイズ比が悪い。V予測（`v = α·ε - σ·x`）はより安定している；SDXL、SD3、Fluxはそれを使う。
- **Classifier-free guidance。** 推論時に、条件付きと無条件の `ε` の両方を計算し、`ε_cfg = (1 + w) · ε_cond - w · ε_uncond`（`w ≈ 3-7`）。レッスン08で扱う。
- **1000ステップは多い。** プロダクションはDDIM（20〜50ステップ）、DPM-Solver（10〜20ステップ）、または蒸留（1〜4ステップ）を使う。レッスン12参照。

## 演習

1. **易。** `code/main.py` でTを40から10に変更する。サンプル品質（出力の視覚的なヒストグラム）はどのように低下するか？どのTで2モード構造が崩壊するか？
2. **中。** ε予測からv予測に切り替える。逆ステップを再導出する。最終的なサンプル品質を比較する。
3. **難。** Classifier-free guidanceを追加する。クラスラベル `c ∈ {0, 1}` で条件付けし、訓練中に10%の確率でドロップし、サンプリング時に `ε = (1+w)·ε_cond - w·ε_uncond` を使う。`w = 0, 1, 3, 7` での条件付きモードヒット率を測定する。

## キーワード

| 用語 | 一般的な言い方 | 実際の意味 |
|------|-----------------|-----------------------|
| フォワードプロセス | 「ノイズを加える」 | データを破壊する固定マルコフ連鎖 `q(x_t \| x_{t-1})`。 |
| リバースプロセス | 「デノイズ」 | データを再構成する学習済み連鎖 `p_θ(x_{t-1} \| x_t)`。 |
| βスケジュール | 「ノイズのはしご」 | ステップごとの分散；線形、コサイン、またはシグモイド。 |
| α̅ | 「アルファバー」 | 累積積 `∏(1 - β)`；`x_0` から `x_t` の閉形式を与える。 |
| 単純な損失 | 「ノイズのMSE」 | `\|\|ε - ε_θ(x_t, t)\|\|²`；すべての変分導出がこれに収束する。 |
| ε予測 | 「ノイズを予測する」 | 出力は加えられたノイズ；標準DDPM。 |
| V予測 | 「速度を予測する」 | 出力は `α·ε - σ·x`；t全体でより良い条件付け。 |
| DDPM | 「あの論文」 | Ho et al. 2020；線形β、1000ステップ、U-Net。 |
| DDIM | 「決定論的サンプラー」 | 非マルコフサンプラー、20〜50ステップ、同じ訓練目的。 |
| Classifier-free guidance | 「CFG」 | 条件付けを増幅するために条件付きと無条件のノイズ予測を混合する。 |

## プロダクションノート：拡散推論はステップ数の問題だ

DDPMの論文はT=1000の逆ステップを実行する。プロダクションで誰もそれを出荷しない。すべての実際の推論スタックは3つの戦略のうち1つを選ぶ——そしてそれぞれが「レイテンシはどこから来るか」というプロダクション的フレーミングにきれいにマッピングされる：

1. **より速いサンプラー、同じモデル。** DDIM（20〜50ステップ）、DPM-Solver++（10〜20）、UniPC（8〜16）。逆ループのドロップイン代替；訓練済みの `ε_θ` ウェイトは変更なし。レイテンシを20〜50倍削減。
2. **蒸留。** より少ないステップで教師にマッチする生徒を訓練する：Progressive Distillation（2→1）、Consistency Models（任意→1〜4）、LCM、SDXL-Turbo、SD3-Turbo。レイテンシをさらに5〜10倍削減、再訓練が必要。
3. **キャッシュとコンパイル。** `torch.compile(unet, mode="reduce-overhead")`、TensorRT-LLMの拡散バックエンド、`xformers`/SDPAアテンション、bf16ウェイト。ステップごとのレイテンシを約2倍削減。（1）と（2）と積み重ね可能。

プロダクション拡散サーバーの予算会話はLLMのプロダクション文献と同じだ：レイテンシは `ステップ数 × ステップコスト + VAEデコード`、スループットは `バッチサイズ × (ステップ数 × ステップコスト)^-1`。TTFTは小さい（1ステップ）；TPOT相当は画像生成がユーザーの視点から「全部一度に」なのでフルレスポンス時間だ。
