# CLIPとコントラスティブ視覚言語事前学習

> OpenAIのCLIP（2021年）は次の5年間を動かすほどの1つのアイデアを証明した：画像エンコーダーとテキストエンコーダーを、ノイズの多いWebの画像キャプションペアとコントラスティブ損失だけを使って同じベクトル空間に整列させる。教師ラベルなし。4億ペア。得られた埋め込み空間はゼロショット分類、画像テキスト検索を実現し、2026年のすべてのVLMのビジョンタワーとして組み込まれている。SigLIP 2（2025年）はsoftmaxをsigmoidに置き換え、低コストでCLIPを超えた。このレッスンではInfoNCEからシグモイドペアワイズ損失までの数学を追い、stdlib PythonでトレーニングステップをゼロBから実装する。


## 学習目標

- 相互情報量からInfoNCE損失を導出し、数値的に安定したベクトル化バージョンを実装する。
- シグモイドペアワイズ損失（SigLIP）がsoftmaxが要求するall-gather オーバーヘッドなしでバッチ32768+にスケールする理由を説明する。
- テキストテンプレート（`a photo of a {class}`）を構築してコサイン類似度のargmaxを取ることでゼロショットImageNet分類を実行する。
- CLIP / SigLIP事前学習が提供する4つのレバーを挙げる：バッチサイズ、温度、プロンプトテンプレート、データ品質。

## 問題

CLIPより前のビジョンは教師ありだった。ラベル付きデータセット（ImageNet：120万画像、1000クラス）を収集し、CNNを学習させ、リリースする。ラベルは高コストで、ラベル付け者が合意できるものへの偏りがあり、ファインチューニングなしに新しいタスクへ移転しない。

Webの画像キャプションには10億以上のゆるくラベル付けされたペアが無料である。「公園の私の犬Max」というalt textのゴールデンレトリバーの写真は監督シグナルを持っている――テキストが画像を説明している。問いは：これを有用な学習に変えられるか？

CLIPの答え：画像キャプションペアをマッチングタスクとして扱う。N枚の画像とNキャプションのバッチが与えられたら、各画像を(N-1)個の外れ値に対して自分のキャプションとマッチさせることを学習させる。教師信号は「これら2つは同じ属す；これらN-1個は属さない」だ。クラスラベルなし。人間のアノテーションなし。ただコントラスティブ損失。

得られた埋め込み空間はCLIPが学習したこと以上のことをする。ImageNetのゼロショットが機能するのは「a photo of a cat」が、明示的にcatとラベル付けされなかった猫の写真の近くに埋め込まれるからだ。これが2026年のすべてのVLMを生んだ賭けだ。

## 概念

### デュアルエンコーダー

CLIPには2つのタワーがある：

- 画像エンコーダー`f`：ViTまたはResNet、画像あたりD次元ベクトルを出力。
- テキストエンコーダー`g`：小さなTransformer、キャプションあたりD次元ベクトルを出力。

両タワーは出力を単位長に正規化する。類似度は`cos(f(x), g(y)) = f(x)^T g(y)`（両方が単位ノルムのため）。

N組の（画像、キャプション）ペアのバッチから、形状`(N, N)`の類似度行列`S`を構築する：

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

`tau`は学習可能な温度（CLIPは0.07で初期化；対数空間で学習）。

### InfoNCE損失

CLIPは行と列に対して対称的なクロスエントロピーを使用する：

```
loss_i2t = CE(S, labels=identity)     # 各画像のポジティブは自身のキャプション
loss_t2i = CE(S^T, labels=identity)   # 各キャプションのポジティブは自身の画像
loss = (loss_i2t + loss_t2i) / 2
```

これがInfoNCEだ。CEのsoftmaxが各画像をバッチ内の他のすべてのキャプションより自分のキャプションとマッチさせることを強制する。「ネガティブ」はすべての他のバッチアイテムだ。大きいバッチ = より多くのネガティブ = 強いシグナル。CLIPはバッチ32kで学習；スケールが重要だ。

### 温度

`tau`はsoftmaxの鋭さを制御する。低いtau → シャープな分布、ハードネガティブマイニング効果。高いtau → ソフト、すべてのサンプルが寄与する。CLIPは`log(1/tau)`を学習し、ほぼゼロのtauへの崩壊を防ぐためにクリップする。SigLIP 2は初期tauを固定して、代わりに学習可能なバイアスを使用する。

### シグモイドがうまくスケールする理由（SigLIP）

Softmaxはすべての類似度行列を同期させる必要がある。分散学習では、softmaxを行う前にすべての埋め込みをすべてのレプリカにall-gatherする必要がある。これはワールドサイズの2乗で通信が増える。

SigLIPはsoftmaxを要素ごとのsigmoidに置き換える：各ペア`(i, j)`について、損失は「これらはマッチするペアか？」の二値分類になる。正クラスラベルは対角線で、それ以外はすべてネガティブだ。損失は：

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1`（`i == j`の場合）、それ以外は0。各ペアの損失は独立している。all-gather不要。各GPUはローカルブロックを計算して合計する。SigLIP 2はCLIPが通信コストを比例して増やす必要がある場所で、バッチ32k〜512kに安価にスケールする。

### ゼロショット分類

N個のクラス名に対して、各クラスのテキストテンプレートを構築する：

```
"a photo of a {class}"
```

テキストエンコーダーで各テンプレートを埋め込む。画像エンコーダーで画像を埋め込む。コサイン類似度のargmax = 予測クラス。対象クラスでの学習なし。

プロンプトテンプレートが重要だ。CLIPの元の論文はクラスあたり80個のテンプレート（通常、芸術的、写真、絵画など）を使用して埋め込みを平均した。+3 ImageNetポイント。現代の使用では通常1〜2個のテンプレートを選ぶ。

### 線形プローブとファインチューニング

ゼロショットはベースラインだ。線形プローブ（対象クラスに対してフリーズしたCLIP特徴の上に1つの線形層を学習させる）はインドメインタスクでゼロショットを上回る。完全ファインチューニングは線形プローブをインドメインで上回るが、ゼロショット転移を損なうことがある。3つのレジームと3つのトレードオフ。

### SigLIP 2：NaFlexと密な特徴

SigLIP 2（2025年）が追加したもの：
- NaFlex：1つのモデルが可変アスペクト比と解像度を処理。
- VLMでのフリーズバックボーンとしての使用を目指した、セグメンテーションと深度推定のためのより優れた密な特徴。
- 多言語：CLIPが英語のみだった場所で100以上の言語で学習。
- CLIPが4億パラメータで頭打ちだった場所で10億パラメータスケール。

2026年のオープンVLMでは、SigLIP 2 SO400m/14がデフォルトのビジョンタワーだ。CLIPは特定のLAION-2B学習分布がクエリパターンにマッチする純粋な画像テキスト検索のデフォルトとして残る。

### ALIGN、BASIC、OpenCLIP、EVA-CLIP

ALIGN（Google、2021年）：CLIPと同じアイデア、18億ペアスケール、90%ノイズ。ノイズの多いデータのスケールを証明。OpenCLIP（LAION）：LAION-400M / 2BでのCLIPのオープン再現、複数スケール、デファクトのオープンチェックポイント。EVA-CLIP：マスク画像モデリングから初期化；VLM向けの強力なバックボーン。BASIC：GoogleのCLIP+ALIGNハイブリッド。すべて同じファミリーで、データと調整が異なる。

### ゼロショットの上限

CLIPクラスのモデルはImageNetゼロショットで約76%（CLIP-G、OpenCLIP-G）が上限だ。それ以上には大幅に多くのデータ（SigLIP 2は80%+を達成）またはアーキテクチャの変更（教師ありヘッド、より多くのパラメータ）が必要だ。ベンチマークは飽和しつつある；真の価値はダウンストリームVLMが消費する埋め込み空間だ。

## 使ってみる

`code/main.py`の実装内容：

1. トイのデュアルエンコーダー（ハッシュベースの画像特徴、テキスト文字特徴）でnumpyなしにInfoNCEの形状を確認できる。
2. pure Python（log-sum-expによる数値安定性）でのInfoNCE損失。
3. 比較のためのシグモイドペアワイズ損失。
4. ゼロショット分類ルーティン：テキストプロンプトのセットに対するコサイン類似度を計算し、予測のためにargmaxをとる。

実行して損失曲線を観察しよう。絶対的な数値はトイのもの；形状は実際のCLIPトレーナーが出力するものと一致する。

## 成果物を出す

このレッスンは`outputs/skill-clip-zero-shot.md`を生成する。画像のセット（パスから）とターゲットクラスのリストが与えられた場合、CLIPテンプレートでテキストプロンプトを構築し、指定されたチェックポイント（例：`openai/clip-vit-large-patch14`）で両側を埋め込み、類似度スコアとともにtop-1/top-5予測を返す。スキルはプロンプトリストにないクラスについての主張を拒否する。

## 演習

1. 4ペアのバッチでInfoNCEを手で実装せよ。4×4の類似度行列を構築し、softmaxを実行し、対角線を取り出し、クロスエントロピーを計算せよ。Pythonの実装をこの手計算と照合して確認せよ。

2. SigLIPはtemperatureに加えてバイアスパラメータ`b`を使用する：`S'[i,j] = S[i,j]/tau + b`。バッチに大きなクラス不均衡（行あたりポジティブよりはるかに多くのネガティブ）がある場合、`b`はどんな役割を果たすか？SigLIP Section 3（arXiv:2303.15343）を読め。

3. 猫vs犬のゼロショット分類器を構築せよ。2つのプロンプトテンプレートを試せ：`a photo of a {class}`と`a picture of a {class}`。100枚のテスト画像で精度を測定せよ。テンプレートのアンサンブルは単一を上回るか？

4. バッチ32kでのsoftmax InfoNCEとシグモイドペアワイズの通信コストを512GPU実行で計算せよ。どちらがO(N)でどちらがO(N^2)でスケールするか？SigLIP Section 4を引用せよ。

5. OpenCLIPスケーリング則論文（arXiv:2212.07143、Chertiら）を読め。図から固定モデルサイズでのデータスケーリングに関する結論を再現せよ：固定モデルサイズで、学習データサイズとImageNetゼロショット精度の対数線形関係は何か？

## キーワード

| 用語 | よく言われること | 実際の意味 |
|------|----------------|------------------------|
| InfoNCE | "コントラスティブ損失" | バッチの類似度行列に対するクロスエントロピー；各アイテムのポジティブはペアになったアイテム、ネガティブは他のすべて |
| シグモイド損失 | "SigLIP損失" | ペアごとの二値クロスエントロピー；softmaxなし、all-gatherなし、分散学習で安価にスケール |
| Temperature | "tau" | softmax/sigmoidの前にロジットをスケールするスカラー；分布の鋭さを制御 |
| ゼロショット | "ファインチューニングなし分類" | テキストプロンプトを使ってクラス埋め込みを構築しコサイン類似度で分類；対象クラスでの学習なし |
| プロンプトテンプレート | "a photo of a ..." | クラス名の周りのテキスト枠；ゼロショット精度に1〜5ポイント影響 |
| デュアルエンコーダー | "Two-tower" | 1つの画像エンコーダー + 1つのテキストエンコーダー、共有D次元空間で出力 |
| ハードネガティブ | "手強いディストラクター" | ポジティブに十分似ていてモデルが区別するために苦労するネガティブ |
| 線形プローブ | "フリーズ + 1層" | フリーズした特徴の上に線形分類器のみを学習させる；特徴品質を測定 |
| NaFlex | "ネイティブ柔軟解像度" | リサイズなしで任意のアスペクト比と解像度で画像を受け取れるSigLIP 2の能力 |
| Temperature scaling | "log-parametrized tau" | CLIPは`log(1/tau)`をパラメータ化してグラジェントが適切に振る舞うようにする；ほぼゼロへの崩壊を防ぐためにクリップ |
