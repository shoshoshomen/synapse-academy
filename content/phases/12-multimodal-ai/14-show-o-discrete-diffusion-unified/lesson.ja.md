# Show-oと離散拡散統合モデル

> Transfusionは連続表現と離散表現を混在させる。Show-o（Xie et al.、2024年8月）はその逆を行く。テキストトークンは因果的な次トークン予測を使い、画像トークンはMaskGITの精神に基づくマスク付き離散拡散を使う。両者は一つのトランスフォーマーにハイブリッドアテンションマスクとともに共存する。その結果、VQA・テキストから画像・インペインティング・混合モダリティ生成が、一つのバックボーン・モダリティごとに一つのトークナイザー・一つの損失定式化（マスク予測に拡張された次トークン）の上に統合される。このレッスンでは、Show-oの設計を説明し、マスク付き離散拡散がなぜ並列的かつ少ステップの画像生成器となるのか、そしてTransfusionやEmu3との比較を行う。


## 学習目標

- マスク付き離散拡散を説明する：トークンを一様にマスクし、トランスフォーマーにその復元を求めるスケジュール。
- 並列画像デコード（Show-o、MaskGIT）と自己回帰的画像デコード（Chameleon、Emu3）を速度と品質の観点で比較する。
- Show-oが一つのチェックポイントで処理する3つのタスクを挙げる：T2I（テキストから画像）、VQA、画像インペインティング。
- マスキングスケジュール（コサイン、線形、打ち切り）を選び、サンプル品質への影響を論じる。

## 問題設定

Transfusionの2損失トレーニングは機能するが、より難しいダイナミクスを持つ。連続拡散損失は、離散NTP損失とは異なる数値スケールで存在する。損失の重みのバランスを取ることはハイパーパラメータ探索となる。アーキテクチャは効果的だが複雑だ。

Show-oの答えは：両モダリティを離散のまま保つ（Chameleonのように）が、画像を逐次的にではなく、マスク付き離散拡散によって並列に生成するというものだ。学習目標は、次トークン予測を自然に一般化した単一のマスクトークン予測になる。

## 概念

### マスク付き離散拡散（MaskGIT）

Chang et al.（2022）によるオリジナルのMaskGITのトリックは優雅だ。完全にマスクされた画像（すべてのトークンが特殊な`<MASK>` ID）から始める。各ステップで、マスクされたすべてのトークンを並列に予測し、最も確信度の高いトップKの予測を保持して残りを再マスクする。約8〜16回の反復後、すべてのトークンが埋まる。各ステップでマスク解除するトークン数のスケジュールはチューニングされており、コサインスケジュールがうまく機能する。

学習は単純だ。マスク比率を[0, 1]から一様サンプリングし、それを画像のVQトークンに適用して、トランスフォーマーがマスクされたトークンを復元するように訓練する。BERTがテキストに対して行ったことを、画像生成にスケールさせたものだ。

### Show-o：一つのトランスフォーマー、ハイブリッドマスク

Show-oはMaskGITを因果言語モデルトランスフォーマーの中に組み込む。アテンションマスクは以下のようになる。

- テキストトークン：因果的（標準LLM）。
- 画像トークン：画像ブロック内で完全な双方向（マスクされたトークンが予測中に他のすべての画像トークンを参照できるよう）。
- テキストから画像：テキストは前の画像に参照し、画像は前のテキストに参照する。

学習は以下を交互に行う。
1. テキスト系列に対する標準NTP。
2. T2Iサンプル：テキスト → 画像（マスクされた画像トークンを使用し、マスクトークン予測損失）。
3. VQAサンプル：画像 → テキスト（マスクされたテキストトークン、実質的にはNTP）。

統一された損失は`<MASK>`トークンに対するクロスエントロピーで、テキストNTP（最後のトークンのみが「マスク」）と画像マスク拡散（ランダムなサブセットがマスク）の両方をカバーする。

### 並列サンプリング

Show-oは、約1000ステップ（トークンごとの自己回帰）や約20ステップ（拡散）ではなく、約16ステップで画像を生成する。各ステップで、マスクされたすべてのトークンを並列に予測し、確信度の高いトップKをコミットして繰り返す。

比較：
- Chameleon / Emu3（トークンの自己回帰）：Nトークンのフォワードパス（画像1枚あたり通常1024〜4096）。
- Transfusion（連続拡散）：約20ステップ、各ステップが完全なトランスフォーマーパス。
- Show-o（マスク付き離散拡散）：約16ステップ、各ステップが完全なトランスフォーマーパス。

Show-oは同規模モデルのChameleonより高速で、ステップ数はTransfusionと同程度だが、ステップあたりのコストは低い（連続MSE損失に対し離散語彙ロジット）。

### 一つのチェックポイントでのタスク

Show-oは推論時にプロンプト形式で選択される4つのタスクをサポートする。

- テキスト生成：標準的な自己回帰テキスト出力。
- VQA：画像入力、テキスト出力。
- T2I：テキスト入力、マスク付き離散拡散による画像出力。
- インペインティング：一部のトークンがマスクされた画像を補完する。

インペインティング機能はマスク予測学習から自然に得られる。VQトークングリッドの一領域をマスクし、残りとテキストプロンプトを入力して、マスクされたトークンを予測する。

### マスキングスケジュール

各ステップでマスク解除するトークン数のスケジュールが品質を左右する。Show-oはコサインを推奨する。

```
mask_ratio(t) = cos(pi * t / (2 * T))   # t = 0..T
```

ステップ0ではすべてのトークンがマスク（比率1.0）。ステップTではマスクなし。コサインは予測が最も有益な中間範囲の比率に質量を集中させる。線形スケジュールも機能するが、より早くプラトーに達する。

### Show-o2

Show-o2（2025年のフォローアップ、arXiv 2506.15564）はShow-oをスケールさせたもので、より大きなLLMベース、改良されたトークナイザー、改善されたマスクスケジュールを持つ。アーキテクチャパターンは同じだ。

### Show-oの位置づけ

2026年の分類では：

- 離散トークン + NTP：Chameleon、Emu3。シンプルだが推論が遅い。
- 離散トークン + マスク拡散：Show-o、MaskGIT、LlamaGen、Muse。並列サンプリング、ただしトークナイザーによる損失あり。
- 連続 + 拡散：Transfusion、MMDiT、DiT。最高品質、より複雑な学習。
- 連続 + VLM内フローマッチング：JanusFlow、InternVL-U。最新。

タスクによる選択：T2I + インペインティング + VQAを一つのオープンモデルで合理的な速度で実現したいならShow-o、品質が最優先で2損失の複雑さを受け入れられるならTransfusion。

## 使ってみる

`code/main.py`はShow-oのサンプリングをシミュレートする。

- 16個のVQトークンからなるおもちゃのグリッド。
- プロンプトと現在マスク解除されているトークンに基づいてロジットを予測するモック「トランスフォーマー」。
- コサインスケジュールで8ステップにわたる並列マスクサンプリング。
- 中間状態（マスクパターンの変化）と最終トークンを出力する。

実行してみると、マスクが段階的に溶けていく様子がわかる。

## 成果物を出す

このレッスンでは`outputs/skill-unified-gen-model-picker.md`を作成する。理解（VQA、キャプション生成）と生成（T2I、インペインティング）の両方が必要で、オープンウェイトの制約があるプロダクトに対して、Show-oファミリー、Transfusion/MMDiTファミリー、Emu3/Chameleonファミリーの中から具体的なトレードオフを示して選択する。

## 演習

1. マスク付き離散拡散は約16ステップでサンプリングする。なぜ1ステップではないのか。ステップ0ですべてをマスク解除すると何が壊れるか？

2. マスク付き拡散ではインペインティングが無料で得られる。Show-oのインペインティングが特化モデルに勝るプロダクトのユースケース（実際または仮定）を提案せよ。

3. コサインスケジュール対線形スケジュール：T=8の場合、各ステップでのマスク解除トークン数を追跡せよ。どちらがよりバランスが取れているか？

4. 512x512のShow-o画像は1024トークンだ。語彙K=16384の場合、モデルは1024 * log2(16384) = 14,336ビット（約1.75 KiB）のデータを出力する。Stable Diffusionは512*512*24ビット = 6,291,456ビット（約768 KiB）の生ピクセルを出力する。圧縮率はいくらか、そしてそれはどのような品質をもたらすか？

5. LlamaGen（arXiv:2406.06525）を読め。LlamaGenのクラス条件付き自己回帰画像モデルはShow-oのマスクアプローチとどう異なるか？

## キーワード

| 用語 | よく使われる表現 | 実際の意味 |
|------|-----------------|------------|
| マスク付き離散拡散 | "MaskGITスタイル" | マスクされたトークンを予測するように学習する。推論時には最も確信度の高い予測を反復的にマスク解除する |
| コサインスケジュール | "マスク解除スケジュール" | 推論ステップにわたるマスク比率の減衰。確信度の成長を中間範囲に集中させる |
| 並列デコード | "全トークン同時" | 各ステップでマスクされたトークン系列全体を1回のフォワードパスで予測し、トップKをコミットする |
| ハイブリッドアテンション | "因果+双方向" | テキストトークンに対して因果的で、画像ブロック内で双方向のマスク |
| インペインティング | "補完生成" | 一部のトークンがマスクされた画像を条件に欠落部分を予測する。学習目標から自然に得られる |
| コミット率 | "ステップごとのトップK" | 反復ごとに「完了」と宣言されるトークン数。推論と品質のトレードオフを制御する |
