# ノルムと距離

> 距離関数は「類似」の定義を決めます。誤った選択は、その後のすべてを壊します。


## 学習目標

- L1、L2、コサイン、マハラノビス、ジャカード、編集距離をゼロから実装する
- 与えられたMLタスクに適切な距離指標を選択し、他の選択肢が失敗する理由を説明する
- L1・L2ノルムをLASSOとリッジ正則化の幾何学的制約領域と結びつける
- 同じデータセットで異なる指標を使うと最近傍が変わることを示す

## 問題の背景

2つのベクトルがあります。単語の埋め込みかもしれません。ユーザープロファイルかもしれません。ピクセル配列かもしれません。問いはこれです：どれだけ近いか？

答えは、どの距離関数を選ぶかによって完全に変わります。2つのデータ点はある指標では最近傍でも、別の指標では遠く離れています。KNN分類器、推薦エンジン、ベクトルデータベース、クラスタリングアルゴリズム、損失関数——これらはすべてこの選択に依存します。間違えると、モデルは誤ったものを最適化します。

普遍的に最良な距離はありません。L2は空間データに機能します。コサイン類似度はNLPを支配します。ジャカードは集合を扱います。編集距離は文字列を扱います。マハラノビスは相関を考慮します。ワッサースタインは確率質量を移動します。それぞれが「類似」の意味について異なる仮定をエンコードしています。

このレッスンでは、主要な距離関数をすべてゼロから構築し、それぞれがいつ適切なツールかを示し、使う指標によって同じデータから完全に異なる最近傍が得られることを実証します。

## 概念

### ノルム：ベクトルの大きさを測る

ノルムはベクトルの「サイズ」を測ります。2つのベクトル間のすべての距離関数は、それらの差のノルムとして書けます：d(a, b) = ||a - b||。したがって、ノルムを理解することは距離を理解することです。

### L1ノルム（マンハッタン距離）

L1ノルムはすべての要素の絶対値を合計します。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

軸方向にしか移動できない（斜めに動けない）都市グリッドでの歩行距離を測るため、マンハッタン距離と呼ばれます。

```
点A = (1, 1)
点B = (4, 5)

L1距離 = |4-1| + |5-1| = 3 + 4 = 7

グリッドでは、東に3ブロック、北に4ブロック歩きます。
```

L1を使う場面：
- 高次元スパースデータ（テキスト特徴量、one-hotエンコーディング）
- 外れ値への頑健性が必要な場合（1つの大きな差が支配しない）
- 特徴量選択問題（L1正則化がスパース性を促進する）

L1正則化（Lasso）との関係：損失関数に||w||_1を加えると、重みの絶対値の和にペナルティを与えます。これにより小さな重みが完全にゼロに押しやられ、自動的な特徴量選択が行われます。L1ペナルティは重み空間でダイヤモンド形の制約領域を作り、ダイヤモンドの角は軸上に位置し、そこで一部の重みがゼロになります。

損失関数との関係：平均絶対誤差（MAE）は予測値と目標値のL1距離の平均です。すべての誤差を線形にペナルティ付けするため、MSEと比べて外れ値に頑健です。

### L2ノルム（ユークリッド距離）

L2ノルムは直線距離です。成分の二乗和の平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

これはジオメトリの授業で学ぶ距離です。n次元のピタゴラスです。

```
点A = (1, 1)
点B = (4, 5)

L2距離 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

グリッドを斜めに切り抜ける直線。
```

L2を使う場面：
- 低〜中次元の連続データ
- 特徴量のスケールが比較可能な場合
- 物理的距離（空間データ、センサー読み取り）
- ピクセルレベルでの画像類似度

L2正則化（リッジ）との関係：損失関数に||w||_2^2を加えると大きな重みにペナルティを与えます。L1と異なり、重みをゼロに押しやりません。すべての重みを比例的にゼロに向けて縮小します。L2ペナルティは円形の制約領域を作るため、軸上に角はありません。重みは小さくなりますが、ほとんどの場合は完全にゼロにはなりません。

損失関数との関係：平均二乗誤差（MSE）はL2距離の二乗の平均です。二乗することで小さな誤差より大きな誤差に対してより重くペナルティを与えます。

```
MAE（L1損失）：|y - y_hat|         線形ペナルティ。外れ値に頑健。
MSE（L2損失）：(y - y_hat)^2       二次ペナルティ。外れ値に敏感。
```

### Lpノルム：一般族

L1とL2はLpノルムの特殊ケースです：

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

pの値によって異なる形の「単位球」（原点から距離1のすべての点の集合）が生まれます：

```
p=1：    ダイヤモンド形      （軸上に角がある）
p=2：    円/球              （通常の丸い球）
p=3：    超楕円体           （角が丸い正方形）
p=inf：  正方形/超立方体     （軸に沿った平らな辺）
```

### L-infinityノルム（チェビシェフ距離）

pが無限大に近づくにつれ、Lpノルムは絶対値最大の成分に収束します。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

2点間の距離は、最も異なる1つの次元によって決まります。他のすべての次元は無視されます。

```
点A = (1, 1)
点B = (4, 5)

L-infinity距離 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

L-infinityを使う場面：
- 任意の単一次元での最悪ケースの偏差が重要な場合
- ゲーム盤（チェスのキングはL-infinityで動く：どの方向に1歩進んでもコスト1）
- 製造公差（すべての次元が仕様内でなければならない）

### コサイン類似度とコサイン距離

コサイン類似度は2つのベクトルの角度を測り、その大きさは無視します。

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

範囲は-1（逆方向）から+1（同方向）です。直交するベクトルはコサイン類似度0になります。

コサイン距離はそれを距離に変換します：cosine_distance = 1 - cosine_similarity。範囲は0（同一方向）から2（逆方向）です。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

コサイン類似度がNLPと埋め込みを支配する理由：テキストでは、文書の長さが類似度に影響すべきではありません。猫についての文書が別の猫についての文書の2倍の長さでも、やはり「類似」しているべきです。コサイン類似度は大きさ（長さ）を無視し、方向だけを考慮します。単語分布が同じで長さが異なる2つの文書は同じ方向を向いており、コサイン類似度1.0を得ます。

コサイン類似度を使う場面：
- テキスト類似度（TF-IDFベクトル、単語埋め込み、文章埋め込み）
- 大きさがノイズで方向がシグナルであるあらゆるドメイン
- 推薦システム（ユーザー嗜好ベクトル）
- 埋め込み検索（ベクトルデータベースはほぼ常にコサインまたはドット積を使用）

### ドット積類似度 vs コサイン類似度

2つのベクトルのドット積は：

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(角度)
```

コサイン類似度は、両方の大きさで正規化されたドット積です。両方のベクトルがすでに単位正規化（大きさ=1）されている場合、ドット積とコサイン類似度は同一です。

```
||a|| = 1 かつ ||b|| = 1 の場合：
    a . b = cos(aとbの間の角度)
```

異なる場合：ドット積には大きさの情報が含まれます。大きさが大きいベクトルほど高いドット積スコアを得ます。これは「人気の高い」アイテムを上位にランク付けしたい一部の検索システムで重要です。大きさは暗黙の品質または重要度シグナルとして機能します。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

方向では一致しますが、ドット積は大きさも反映します。
```

実用上：
- 純粋な方向類似度が必要な場合はコサイン類似度を使用
- 大きさが意味のある情報を持つ場合はドット積を使用
- 多くのベクトルデータベース（Pinecone、Weaviate、Qdrant）はどちらかを選択できる
- 埋め込みがL2正規化されている場合は選択が変わらない

### マハラノビス距離

ユークリッド距離はすべての次元を均等に扱います。しかし特徴量が相関していたり、スケールが異なる場合、L2は誤解を招く結果を与えます。

マハラノビス距離はデータの共分散構造を考慮します。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

ここでSはデータの共分散行列です。

直感的に：マハラノビス距離はまずデータを無相関化・正規化（白色化）し、その変換された空間でL2距離を計算します。Sが単位行列（無相関、単位分散の特徴量）の場合、マハラノビス距離はユークリッド距離に帰着します。

```
例：身長と体重は相関している。
6フィート2インチで180ポンドは珍しくない。
5フィートで180ポンドは珍しい。

ユークリッド距離は両者が平均から等しく離れていると言うかもしれない。
マハラノビス距離は身長と体重の相関を考慮して
2番目の人を正しく外れ値として識別する。
```

マハラノビス距離を使う場面：
- 外れ値検出（平均からのマハラノビス距離が大きい点が外れ値）
- 特徴量のスケールと相関が異なる場合の分類
- 信頼できる共分散行列を推定するのに十分なデータがある場合
- 製造業の品質管理（多変量プロセス監視）

### ジャカード類似度（集合向け）

ジャカード類似度は2つの集合の重なりを測ります。

```
J(A, B) = |A ∩ B| / |A ∪ B|
```

範囲は0（重なりなし）から1（同一集合）です。ジャカード距離 = 1 - ジャカード類似度。

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

積集合 = {cat, fish}             サイズ = 2
和集合 = {cat, dog, fish, bird, snake}  サイズ = 5

ジャカード類似度 = 2/5 = 0.4
ジャカード距離 = 0.6
```

ジャカードを使う場面：
- タグ、カテゴリ、特徴量の集合比較
- 単語の存在（頻度ではない）に基づく文書類似度
- 近似重複検出（ジャカードのMinHash近似）
- バイナリ特徴量ベクトルの比較（存在/不在データ）
- セグメンテーションモデルの評価（Intersection over Union = ジャカード）

### 編集距離（レーベンシュタイン距離）

編集距離は、1つの文字列を別の文字列に変換するために必要な最小限の1文字操作の回数を数えます。操作は：挿入、削除、置換。

```
"kitten" -> "sitting"

kitten -> sitten  （k → s に置換）
sitten -> sittin  （e → i に置換）
sittin -> sitting （g を挿入）

編集距離 = 3
```

動的計画法で計算します。エントリ(i, j)が文字列Aの最初のi文字と文字列Bの最初のj文字の編集距離である行列を埋めます。

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

編集距離を使う場面：
- スペルチェックと修正
- DNA配列アライメント（重み付き操作で）
- ファジー文字列マッチング
- 乱雑なテキストデータの重複除去

### KLダイバージェンス（距離ではないが距離として使われる）

KLダイバージェンスは、ある確率分布が別の確率分布とどれだけ異なるかを測ります。レッスン09で扱いましたが、距離ではないにもかかわらず人々が「距離」として使うためここでの議論にも含まれます。

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

重要な性質：KLダイバージェンスは対称ではありません。

```
D_KL(P || Q) != D_KL(Q || P)
```

これは距離指標の基本要件を満たさないことを意味します。三角不等式も満たしません。これはダイバージェンスであり、距離ではありません。

順方向KL（D_KL(P || Q)）は「平均追求型」：QはPのすべてのモードをカバーしようとします。
逆方向KL（D_KL(Q || P)）は「モード追求型」：QはPの1つのモードに集中します。

KLダイバージェンスを見かける場面：
- VAE（ELBOのKL項が潜在分布を事前分布に向けて押し付ける）
- 知識蒸留（学生が教師の分布に合わせようとする）
- RLHF（KLペナルティがファインチューニングされたモデルをベースモデルに近い状態に保つ）
- 方策勾配法（方策の更新を制約する）

### ワッサースタイン距離（アースムーバー距離）

ワッサースタイン距離は、ある確率分布を別の確率分布に変換するために必要な最小「仕事量」を測ります。イメージ：ある分布が土の山で、別の分布が穴であれば、どれだけの土をどれだけ移動させる必要があるか。

```
W(P, Q) = すべての輸送計画γについての E[d(x, y)] の下限
```

1次元分布では、累積分布関数の絶対差の積分に簡略化されます：

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

ワッサースタインが重要な理由：
- 真の指標（対称、三角不等式を満たす）
- 分布が重ならない場合でも勾配を提供（KLダイバージェンスは無限大になる）
- この性質により、元のGANの学習不安定性を解決したワッサースタインGAN（WGAN）の中心となった

```
重ならない分布：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KLダイバージェンス：無限大（ゼロの対数）
ワッサースタイン：4（すべての質量を4ビン移動）

ワッサースタインは意味のある勾配を与える。KLは与えない。
```

ワッサースタインを使う場面：
- GAN学習（WGAN、WGAN-GP）
- 重ならない可能性のある分布の比較
- 最適輸送問題
- 画像検索（カラーヒストグラムの比較）

### タスクごとに異なる距離が必要な理由

| タスク | 最適な距離 | 理由 |
|-------|-----------|------|
| テキスト類似度 | コサイン | 大きさはノイズ、方向が意味 |
| 画像ピクセル比較 | L2 | 空間的関係が重要、特徴量は同等スケール |
| スパース高次元特徴量 | L1 | 頑健、稀な大きな差を増幅しない |
| 集合の重なり（タグ、カテゴリ） | ジャカード | データが自然に集合値、ベクトルではない |
| 文字列マッチング | 編集距離 | 操作が人間の編集直感に対応 |
| 外れ値検出 | マハラノビス | 特徴量の相関とスケールを考慮 |
| 分布の比較 | KLダイバージェンス | QでなくPを使った場合の情報損失を測る |
| GAN学習 | ワッサースタイン | 分布が重ならない場合でも勾配を提供 |
| 埋め込み（ベクトルDB） | コサインまたはドット積 | 埋め込みは方向に意味をエンコードするよう学習 |
| 推薦 | ドット積 | 大きさが人気度や信頼度をエンコードできる |
| DNA配列 | 重み付き編集距離 | 置換コストがヌクレオチドペアによって異なる |
| 製造品質管理 | L-infinity | 任意の次元での最悪ケースの偏差が重要 |

### 損失関数との関係

損失関数は予測値と目標値に適用される距離関数です。

```
損失関数        使用する距離         挙動
MSE             L2の二乗            大きな誤差に重くペナルティを与える
MAE             L1                  すべての誤差に均等にペナルティを与える
フーバー損失    大きな誤差にL1、    両方の良い点：外れ値に頑健、
                小さな誤差にL2      ゼロ付近で滑らかな勾配
クロスエントロピー KLダイバージェンス 分布の不一致を測る
ヒンジ損失      max(0, マージン-d)   マージン以下のみにペナルティを与える
トリプレット損失 L2（通常）          正例を近づけ、負例を遠ざける
対照損失        L2                  類似ペアを近く、非類似ペアをマージン以上に
```

### 正則化との関係

正則化は損失関数に重みのノルムペナルティを加えます。

```
L1正則化（Lasso）：  loss + lambda * ||w||_1
  -> スパースな重み。一部の重みが完全にゼロになる。
  -> 自動的な特徴量選択。
  -> ゼロで非微分可能な解（コーナーを持つ）。

L2正則化（リッジ）：  loss + lambda * ||w||_2^2
  -> 小さな重み。すべての重みがゼロに向けて縮小する。
  -> 特徴量選択なし（何もゼロに完全にはならない）。
  -> どこでも滑らかな解。

Elastic Net：         loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> L1のスパース性とL2の安定性を組み合わせる。
  -> 相関する特徴量グループは一緒に保持または削除される。
```

L1はスパース性を生むがL2は生まない理由：2次元重み空間で制約領域を描きます。L1はダイヤモンド、L2は円です。損失関数の等高線（楕円）がダイヤモンドに触れる最初の点は角（1つ以上の重みがゼロの場所）である可能性が最も高いです。等高線が円に触れる点は滑らかなため、すべての重みが非ゼロです。

### 最近傍探索

すべての距離関数は最近傍探索問題を含意します：クエリ点を与えられたとき、データセット中の最も近い点を見つけます。

厳密な最近傍探索はn点d次元のデータセットでクエリごとにO(n * d)です。大規模データセットでは遅すぎます。

近似最近傍（ANN）アルゴリズムは少量の精度を犠牲にして大幅な速度向上を実現します：

```
アルゴリズム       アプローチ                    使用先
KDツリー          軸平行空間分割                 scikit-learn（低次元）

```

HNSW（Hierarchical Navigable Small World）は現代のベクトルデータベースで主流のアルゴリズムです。各ノードが近似最近傍に接続する多層グラフを構築します。検索は最上層（疎、長距離ジャンプ）から始まり最下層（密、短距離ジャンプ）へ降りていきます。

## 実装

### ステップ1：すべてのノルムと距離関数

完全な実装は`code/distances.py`を参照してください。すべての関数は基本的なPythonの数学演算のみを使ってゼロから構築されています。

### ステップ2：同じデータ、異なる距離、異なる最近傍

`distances.py`のデモはデータセットを作成し、クエリ点を選択し、距離指標によって最近傍がどう変わるかを示します。L1での「最も近い」点がL2やコサインでの最も近い点ではない場合があります。

コードには、L2距離とコサイン類似度を使ってクエリに最も類似した「文書」を見つけるモック埋め込み類似度検索が含まれており、ランキングが異なる場合があることを示します。

## 活用

最も一般的な実用的ユースケース：ベクトルデータベースで類似アイテムを見つける。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"アイテム0に最も類似した上位5件: {top_k}")
print(f"類似度: {similarities[top_k]}")
```

`model.encode(text)`を呼んでベクトルデータベースを検索するとき、裏側ではこのことが起きています。埋め込みモデルがテキストをベクトルにマッピングします。ベクトルデータベースはクエリベクトルと格納されたすべてのベクトルのコサイン類似度（またはドット積）を計算し、ANNアルゴリズムを使ってすべてを確認しないようにします。

## 演習

1. (1, 2, 3)と(4, 0, 6)のL1、L2、L-infinity距離を計算します。任意の点のペアに対してL-inf <= L2 <= L1が常に成立することを検証します。この順序が保証される理由を証明してください。

2. コサイン類似度が高い（> 0.9）がL2距離が大きい（> 10）2つのベクトルを作成します。何が起きているか幾何学的に説明してください。次にコサイン類似度が低い（< 0.3）がL2距離が小さい（< 0.5）2つのベクトルを作成します。

3. データセットとクエリ点を受け取り、L1、L2、コサイン、マハラノビス距離での最近傍を返す関数を実装します。4つすべてが最も近い点について異なる結論を出すデータセットを見つけてください。

4. CDFメソッドを使って[0.5, 0.5, 0, 0]と[0, 0, 0.5, 0.5]のワッサースタイン距離を手計算します。次に[0.25, 0.25, 0.25, 0.25]と[0, 0, 0.5, 0.5]のワッサースタイン距離を計算します。どちらが大きいですか、なぜですか？

5. ジャカード類似度の近似のためにMinHashを実装します。100個のランダムな集合を生成し、すべてのペアの厳密なジャカードを計算して、50、100、200のハッシュ関数を使ったMinHash近似と比較します。近似誤差をプロットしてください。

## キー用語

| 用語 | よく言われる説明 | 実際の意味 |
|------|----------------|------------|
| ノルム | 「ベクトルのサイズ」 | ベクトルを非負スカラーにマッピングする関数で、三角不等式、絶対的斉次性、ゼロベクトルのみでゼロになる性質を満たす |
| L1ノルム | 「マンハッタン距離」 | 絶対値成分の和。最適化においてスパース性を生む。外れ値に頑健 |
| L2ノルム | 「ユークリッド距離」 | 成分の二乗和の平方根。ユークリッド空間における直線距離 |
| Lpノルム | 「一般化ノルム」 | 絶対値成分のp乗の和のp乗根。L1とL2は特殊ケース |
| L-infinityノルム | 「最大ノルム」または「チェビシェフ距離」 | 絶対値最大の成分値。pが無限大に近づいたLpの極限 |
| コサイン類似度 | 「ベクトル間の角度」 | 両方の大きさで正規化されたドット積。-1から+1の範囲。ベクトルの長さを無視 |
| コサイン距離 | 「1 - コサイン類似度」 | コサイン類似度を距離に変換する。0から2の範囲 |
| ドット積 | 「正規化されていないコサイン」 | 成分ごとの積の和。両方の大きさとコサイン類似度の積と等しい |
| マハラノビス距離 | 「相関を考慮した距離」 | データの共分散行列を使って白色化（無相関化・正規化）された空間でのL2距離 |
| ジャカード類似度 | 「集合の重なり」 | 積集合のサイズを和集合のサイズで割ったもの。ベクトルではなく集合のため |
| 編集距離 | 「レーベンシュタイン距離」 | 1つの文字列を別の文字列に変換するための最小挿入・削除・置換回数 |
| KLダイバージェンス | 「分布間の距離」 | 真の距離ではない（対称でない）。QでPをエンコードする場合の追加ビット数を測る |
| ワッサースタイン距離 | 「アースムーバー距離」 | ある分布から別の分布へ質量を輸送するための最小仕事量。真の指標 |
| 近似最近傍 | 「ANN探索」 | 厳密な探索より大幅に速く近似的に最も近い点を見つけるアルゴリズム（HNSW、LSH、IVF） |
| HNSW | 「ベクトルDBアルゴリズム」 | 階層的ナビゲーブルスモールワールドグラフ。高速な近似最近傍探索のための多層グラフ |
| L1正則化 | 「Lasso」 | 損失に重みのL1ノルムを加える。重みをゼロに押しやる（スパース性） |
| L2正則化 | 「リッジ」または「重み減衰」 | 損失に重みのL2ノルムの二乗を加える。スパース性なしに重みをゼロに縮小 |
| Elastic Net | 「L1 + L2」 | L1とL2正則化を組み合わせる。相関する特徴量グループをどちらか単体より上手く処理 |
