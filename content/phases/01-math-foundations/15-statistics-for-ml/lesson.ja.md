# 機械学習のための統計学

> 統計学は、モデルが本当に機能しているのか、それとも運が良かっただけなのかを知る手段です。


## 学習目標

- 記述統計量、ピアソン/スピアマン相関、共分散行列をゼロから計算する
- 仮説検定（t検定、カイ二乗検定）を実施し、p値と信頼区間を正しく解釈する
- ブートストラップ再サンプリングを使って、分布の仮定なしに任意の指標の信頼区間を構築する
- 効果量の指標を使って統計的有意性と実践的有意性を区別する

## 問題の背景

2つのモデルを学習しました。モデルAはテストセットで0.87のスコア。モデルBは0.89。モデルBをデプロイしました。3週間後、本番指標が以前より悪化しています。何が起きたのでしょうか？

モデルBは実際にはモデルAを上回っていませんでした。0.02の差はノイズだったのです。テストセットが小さすぎたか、分散が高すぎたか、あるいはその両方です。改善を装ったランダム性をデプロイしてしまいました。

これは常に起きています。Kaggleリーダーボードの順位変動。再現できない論文。数百のサンプルに基づいて勝者を宣言するA/Bテスト。根本原因はいつも同じです：誰かが統計をスキップしたのです。

統計学はシグナルとノイズを区別するツールを与えてくれます。違いが本物かどうか、どれだけ自信を持つべきか、結果を信頼できるようになるまでにどれだけのデータが必要かを教えてくれます。すべてのMLパイプライン、すべてのモデル比較、すべての実験には統計が必要です。それなしでは、当てずっぽうです。

## 概念

### 記述統計：データを要約する

何かをモデル化する前に、データがどんな形をしているかを知る必要があります。記述統計はデータセットをその形状を捉えた少数の数値に圧縮します。

**中心傾向の指標**は「中心はどこか？」に答えます。

```
平均：  全値の合計 / データ数
        mu = (1/n) * sum(x_i)

中央値：並び替えたときの中央値
        外れ値に頑健。[1, 2, 3, 4, 1000] の場合、平均は202だが
        中央値は3。

最頻値：最も多く現れる値
        カテゴリデータに有用。連続データではほとんど情報がない。
```

平均は均衡点です。中央値は折り返し点です。両者が乖離するとき、分布は歪んでいます。所得分布は平均 >> 中央値（億万長者による右歪み）。学習中の損失分布はしばしば平均 << 中央値（簡単なサンプルによる左歪み）。

**散布の指標**は「データはどれだけ分散しているか？」に答えます。

```
分散：    平均からの偏差の二乗の平均
          sigma^2 = (1/n) * sum((x_i - mu)^2)

標準偏差：分散の平方根
          sigma = sqrt(sigma^2)
          データと同じ単位なので、より解釈しやすい。

範囲：    最大値 - 最小値
          外れ値に敏感。単独ではほとんど有用でない。

IQR：     Q3 - Q1（四分位範囲）
          データの中央50%の範囲。
          外れ値に頑健。箱ひげ図と外れ値検出に使用。
```

**パーセンタイル**は並び替えたデータを100等分します。25パーセンタイル（Q1）は25%の値がこの点より下にあることを意味します。50パーセンタイルは中央値です。75パーセンタイルはQ3です。

```
レイテンシ監視では：
  P50 = 中央値レイテンシ        （典型的なユーザー体験）
  P95 = 95パーセンタイル        （悪いが最悪ではない）
  P99 = 99パーセンタイル        （テールレイテンシ、多くの場合中央値の10倍）
```

MLでは、推論レイテンシ、予測信頼度の分布、エラー分布の理解のためにパーセンタイルに注目します。平均エラーは低いがP99エラーが酷いモデルは、安全性が重要なアプリケーションでは役に立たないかもしれません。

**サンプル統計 vs 母集団統計**。サンプルから分散を計算するとき、nではなく(n-1)で割ります。これがベッセルの補正です。サンプルの平均は真の母集団の平均ではないという事実を補正します。分母にnを使うと、真の分散を系統的に過小評価します。(n-1)を使うと、推定値は不偏になります。

```
母集団分散：sigma^2 = (1/N) * sum((x_i - mu)^2)
サンプル分散：s^2  = (1/(n-1)) * sum((x_i - x_bar)^2)
```

実用上：nが大きい場合（数千サンプル）、差は無視できます。nが小さい場合（数十サンプル）、重要です。

### 相関：変数がどのように一緒に動くか

相関は2つの変数間の線形関係の強さと方向を測ります。

**ピアソン相関係数**は線形の関連性を測ります：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1：  完全な正の線形関係
r = -1：  完全な負の線形関係
r =  0：  線形関係なし（しかし非線形の関係がある可能性はある！）

範囲：[-1, 1]
```

ピアソンは関係が線形で両変数がほぼ正規分布していることを前提とします。外れ値に敏感です。1つの極端な点がrを0.1から0.9に押し上げる可能性があります。

**スピアマン順位相関**は単調な関連性を測ります：

```
1. 各値をその順位（1、2、3...）に置き換える
2. 順位についてピアソン相関を計算する

スピアマンは線形だけでなく単調な関係を捉える。
y = x^3 の場合、ピアソンはr < 1を返すが、スピアマンはrho = 1を返す。
```

**それぞれをいつ使うか：**

```
ピアソン：  両変数が連続的でほぼ正規分布している場合。
            線形関係に特に関心がある場合。
            極端な外れ値がない場合。

スピアマン：順序データ（ランキング、評価）。
            データが正規分布していない場合。
            線形ではなく単調な関係が疑われる場合。
            外れ値が存在する場合。
```

**黄金律：** 相関は因果を意味しません。アイスクリームの販売量と溺死の死亡者数は相関しています。なぜなら両方とも夏に増えるからです。モデルの精度とパラメータ数は相関していますが、パラメータを追加しても自動的に精度が向上するわけではありません（過学習を参照）。

### 共分散行列

2変数の共分散は、それらがどのように一緒に変動するかを測ります：

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0：  XとYは一緒に増加する傾向がある
Cov(X, Y) < 0：  Xが増加するとYは減少する傾向がある
Cov(X, Y) = 0：  線形的な共変動なし
```

d個の特徴量に対して、共分散行列CはC[i][j] = Cov(特徴量_i, 特徴量_j)であるd×d行列です。対角要素C[i][i]は各特徴量の分散です。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性質：
  - 対称：C[i][j] = C[j][i]
  - 半正定値：すべての固有値 >= 0
  - 対角 = 分散
  - 非対角 = 共分散
```

**PCAとの関係。** PCAは共分散行列を固有値分解します。固有ベクトルが主成分（最大分散の方向）です。固有値は各成分がどれだけの分散を捉えるかを示します。これがレッスン10で扱ったことですが、ここで共分散行列を分解することが適切である理由がわかります：データのすべてのペアの線形関係をエンコードするからです。

**相関との関係。** 相関行列は標準化された変数（それぞれを標準偏差で割った）の共分散行列です。相関はすべての値が[-1, 1]に収まるように共分散を正規化します。

### 仮説検定

仮説検定は不確実性の下での意思決定のフレームワークです。主張から始め、データを収集し、データがその主張と整合しているかどうかを判断します。

**セットアップ：**

```
帰無仮説 (H0)：        デフォルトの仮定、通常は「効果なし」
対立仮説 (H1)：        示そうとしていること

例：
  H0：モデルAとモデルBは同じ精度を持つ
  H1：モデルBはモデルAより高い精度を持つ
```

**p値**は、H0が真であると仮定した場合に、観察したデータと同じくらい極端なデータを見る確率です。H0が真である確率ではありません。これは統計学で最も一般的な誤解です。

```
p値 = P(これほど極端なデータ | H0が真である)

p値 < alpha（通常0.05）の場合：
    H0を棄却する。結果は「統計的に有意」。
p値 >= alpha の場合：
    H0を棄却しない。十分な証拠がない。
    H0が真であるということではない。
```

**信頼区間**はパラメータの妥当な値の範囲を与えます：

```
平均の95%信頼区間：
    x_bar +/- z * (s / sqrt(n))

95%信頼には z = 1.96

解釈：この実験を何度も繰り返すと、計算された区間の95%が真の
平均を含むだろう。この特定の区間に真の平均が含まれる確率が
95%ではない。
```

信頼区間の幅は精度を教えてくれます。幅が広い区間は不確実性が高いことを意味します。狭い区間は推定値が精密であることを意味します（ただし、データに偏りがあれば正確ではないかもしれない）。

### t検定

t検定は平均を比較します。いくつかの種類があります。

**一標本t検定：** 母集団の平均は仮説値と異なるか？

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**二標本t検定（独立）：** 2つのグループの平均は異なるか？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

これは等分散を仮定しないウェルチのt検定。
等分散に特別な理由がない限りは常にウェルチを使う。
```

**対応のあるt検定：** 測定値がペアで得られる場合（同じデータ分割で評価された同じモデル）：

```
各ペアについて d_i = x_i - y_i を計算する
次にmu_0 = 0に対するd_i値の一標本t検定を実行する
```

MLでは対応のあるt検定が一般的です：両モデルを同じ10個のクロスバリデーションフォールドで実行し、スコアをペアで比較します。

### カイ二乗検定

カイ二乗検定は観測頻度が期待頻度と一致するかどうかを確認します。カテゴリデータに有用です。

```
chi^2 = sum((観測値 - 期待値)^2 / 期待値)

例：言語モデルの出力分布が
カテゴリ全体の学習分布と一致するか？

カテゴリ    観測値   期待値
ポジティブ    120      100
ネガティブ     80      100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

自由度1で、chi^2 = 8 は p < 0.005 を与える。
差は有意。
```

### MLモデルのA/Bテスト

MLにおけるA/BテストはウェブのA/Bテストとは異なります。モデル比較には特有の課題があります：

```
1. 同じテストセット：  両モデルは同一のデータで評価されなければならない。
                        異なるテストセットでは比較が無意味になる。

2. 複数指標：          精度だけでは不十分。適合率、再現率、F1、
                        レイテンシ、公平性指標が必要。

3. 分散：              点推定だけでなく、クロスバリデーションや
                        ブートストラップを使って各指標の分散を推定する。

4. データ漏洩：        モデル選択中にテストセットが使用されていた場合、
                        比較に偏りがある。最終テストセットを取っておく。
```

**手順：**

```
1. 指標と有意水準（alpha = 0.05）を定義する
2. 両モデルを同じk分割クロスバリデーション分割で実行する
3. ペアスコアを収集：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 差を計算：d_i = b_i - a_i
5. 差に対して対応のあるt検定を実行する
6. チェック：平均の差は0と有意に異なるか？
7. 平均の差の信頼区間を計算する
8. 実践的有意性を判断するために効果量（コーエンのd）を計算する
```

### 統計的有意性 vs 実践的有意性

結果は統計的に有意でも実践的には無意味な場合があります。十分なデータがあれば、些細な差でも統計的に有意になります。

```
例：
  モデルAの精度：0.9234
  モデルBの精度：0.9237
  n = 1,000,000 テストサンプル
  p値 = 0.001

統計的に有意？ はい。
実践的に有意？ 0.03%の改善は新しいモデルをデプロイする
エンジニアリングコストに見合わない。
```

**効果量**はサンプルサイズに依存しない差の大きさを定量化します：

```
コーエンのd = (平均値_1 - 平均値_2) / プールされた標準偏差

d = 0.2：  小さな効果
d = 0.5：  中程度の効果
d = 0.8：  大きな効果
```

p値と効果量の両方を報告してください。p値は差が本物かどうかを示します。効果量は重要かどうかを示します。

### 多重比較の問題

多くの仮説を検定すると、いくつかは偶然に「有意」になります。alpha = 0.05で20個のことを検定すると、何も本物でなくても1つの偽陽性が出ることが期待されます。

```
P(少なくとも1つの偽陽性) = 1 - (1 - alpha)^m

m = 20 検定, alpha = 0.05：
P(偽陽性) = 1 - 0.95^20 = 0.64

少なくとも1つの偽陽性が出る可能性が64%。
```

**ボンフェローニ補正：** 検定数でalphaを割る。

```
調整後alpha = alpha / m = 0.05 / 20 = 0.0025

p値 < 0.0025 の場合のみH0を棄却する。
保守的だがシンプル。検定が独立している場合に機能する。
```

MLでは、複数の指標にわたるモデル比較、多数のハイパーパラメータ設定のテスト、複数のデータセットでの評価を行う場合に重要です。

### ブートストラップ法

ブートストラップは、データを復元抽出でリサンプリングすることで統計量のサンプリング分布を推定します。基礎となる分布についての仮定は不要です。

**アルゴリズム：**

```
1. n個のデータ点がある
2. 復元抽出でn個のサンプルを取る（一部の点は複数回出現し、
   一部はまったく出現しない）
3. このブートストラップサンプルで統計量を計算する
4. B回繰り返す（通常B = 1000〜10000）
5. ブートストラップ統計量の分布がサンプリング分布を近似する
```

**ブートストラップ信頼区間（パーセンタイル法）：**

```
B個のブートストラップ統計量を並び替える
95% CI = [2.5パーセンタイル, 97.5パーセンタイル]
```

**ブートストラップがMLにとって重要な理由：**

```
- テストセット精度は点推定。ブートストラップは信頼区間を与える。
- 指標の分布が正規分布であると仮定できない（特にAUC、F1、
  precision at k）。
- ブートストラップは任意の統計量に機能する：中央値、2つの平均の比、
  2つのモデルのAUCの差。
- 解析的な式は不要。
```

**モデル比較のためのブートストラップ：**

```
1. 同じテストセットでモデルAとモデルBの予測がある
2. 各ブートストラップ反復で：
   a. 復元抽出でテストインデックスをリサンプリングする
   b. リサンプリングされたセットでmetric_AとmetricBを計算する
   c. diff = metric_B - metric_A を保存する
3. 差の95% CI：
   [diffの2.5パーセンタイル, diffの97.5パーセンタイル]
4. CIが0を含まなければ、差は有意
```

これは分布の仮定をしないため、対応のあるt検定より頑健です。

### パラメトリック検定 vs ノンパラメトリック検定

**パラメトリック検定**は特定の分布（通常は正規分布）を仮定します：

```
t検定：        正規分布データを仮定（またはCLTによる大きなn）
ANOVA：        正規性と等分散を仮定
ピアソンr：   二変量正規性を仮定
```

**ノンパラメトリック検定**は分布の仮定をしません：

```
マン・ホイットニーU検定：   2グループの比較（独立t検定の代替）
ウィルコクソン符号付き順位検定：ペアデータの比較（対応のあるt検定の代替）
スピアマンrho：              順位の相関（ピアソンの代替）
クラスカル・ウォリス検定：   複数グループの比較（ANOVAの代替）
```

**ノンパラメトリックをいつ使うか：**

```
- 小サンプルサイズ（n < 30）でデータが明らかに非正規分布
- 順序データ（評価、ランキング）
- 取り除けない重い外れ値
- 歪んだ分布
```

**パラメトリックをいつ使うか：**

```
- 大サンプルサイズ（CLTが検定統計量をほぼ正規分布にする）
- データが極端な外れ値なくほぼ対称
- より高い統計的検出力（実際の差をより上手く検出できる）
```

ML実験では通常nが小さい（5または10クロスバリデーションフォールド）ため、ウィルコクソン符号付き順位検定などのノンパラメトリック検定がt検定よりも適切なことが多いです。

### 中心極限定理：実践的な含意

CLTは、基礎となる母集団分布に関係なく、nが大きくなるにつれてサンプル平均の分布が正規分布に近づくと言います。

```
X_1, X_2, ..., X_n が平均muと分散sigma^2を持つiidならば：

    X_bar ~ Normal(mu, sigma^2 / n)    n -> 無限大のとき

ほとんどの場合n >= 30で機能する。
高度に歪んだ分布ではn >= 100が必要かもしれない。
```

**MLにとっての重要性：**

```
1. 集計指標への信頼区間とt検定を正当化する
2. 個々のフォールドが激しく変動しても、クロスバリデーション
   フォールドを平均することで安定した推定値が得られる理由を説明する
3. ミニバッチ勾配降下法：バッチ上の平均勾配が真の勾配を近似する
   （CLTの実際）
4. アンサンブル法：多くのモデルの予測を平均することで、
   単一のモデルよりも安定した出力を得る
```

**CLTがしないこと：**

```
- データを正規分布にはしない。サンプルの平均を正規分布にする。
- 無限分散の重い裾分布（コーシー分布）には機能しない。
- 修正なしに依存データ（時系列）には適用されない。
```

### ML論文における統計的なよくある誤り

1. **訓練セットでのテスト。** 過学習が保証される。常に学習中にモデルが見ないデータを取り置く。

2. **信頼区間なし。** 不確実性なしに単一の精度の数値を報告することで、結果が再現不可能で検証不可能になる。

3. **多重比較の無視。** 50の設定をテストして補正なしに最良のものを報告することで偽陽性率が膨らむ。

4. **統計的有意性と実践的有意性の混同。** 0.01%の精度向上でp値0.001は意味がない。

5. **不均衡データでの精度の使用。** 99%ネガティブクラスのデータセットで99%の精度はモデルが何も学習していないことを意味する。適合率、再現率、F1、またはAUCを使う。

6. **指標のつまみ食い。** モデルが勝つ指標だけを報告する。正直な評価はすべての関連指標を報告する。

7. **訓練/テスト分割をまたいだ情報漏洩。** 分割前に正規化したり、過去を予測するのに未来のデータを使う。

8. **分散推定なしの小さなテストセット。** 100サンプルで評価して2%の改善を主張することはノイズであって、シグナルではない。

9. **データが独立でないのに独立と仮定する。** 同じ患者からの医療画像、同じ文書からの複数の文。グループ内の観測値は相関している。

10. **p値ハッキング。** p < 0.05になるまで異なる検定、サブセット、除外基準を試す。結果はその探索のアーティファクト。

## 実装

以下を実装します：

1. **ゼロからの記述統計**（平均、中央値、最頻値、標準偏差、パーセンタイル、IQR）
2. **相関関数**（ピアソンとスピアマン、共分散行列も含む）
3. **仮説検定**（一標本t検定、二標本t検定、カイ二乗検定）
4. **ブートストラップ信頼区間**（任意の統計量、仮定不要）
5. **A/Bテストシミュレーター**（データ生成、テスト、第一種・第二種誤りの確認）
6. **統計的有意性 vs 実践的有意性のデモ**（大きなnがすべてを「有意」にすることを示す）

すべてをゼロから、`math`と`random`のみを使って実装します。numpy、scipyは使いません。

## キー用語

| 用語 | 定義 |
|------|------|
| 平均 | 値の合計をデータ数で割ったもの。外れ値に敏感。 |
| 中央値 | 並び替えたデータの中央値。外れ値に頑健。 |
| 標準偏差 | 分散の平方根。元の単位での散布を測る。 |
| パーセンタイル | 与えられた割合のデータがその点より下に落ちる値。 |
| IQR | 四分位範囲。Q3からQ1を引いたもの。中央50%の散布。 |
| ピアソン相関 | 2変数間の線形の関連性を測る。範囲[-1, 1]。 |
| スピアマン相関 | 順位を使った単調な関連性を測る。 |
| 共分散行列 | すべての特徴量間のペアの共分散の行列。 |
| 帰無仮説 | 効果なしまたは差なしのデフォルトの仮定。 |
| p値 | 帰無仮説が真である場合に、これほど極端なデータを見る確率。 |
| 信頼区間 | 与えられた信頼水準でのパラメータの妥当な値の範囲。 |
| t検定 | 平均が有意に異なるかどうかを検定する。t分布を使用。 |
| カイ二乗検定 | 観測頻度が期待頻度と異なるかどうかを検定する。 |
| 効果量 | サンプルサイズに依存しない差の大きさ。コーエンのdが一般的。 |
| ボンフェローニ補正 | 偽陽性を制御するために検定数で有意閾値を割る。 |
| ブートストラップ | サンプリング分布を推定するための復元抽出による再サンプリング。 |
| 第一種誤り | 偽陽性。H0が真のときにH0を棄却する。 |
| 第二種誤り | 偽陰性。H0が偽のときにH0を棄却しない。 |
| 統計的検出力 | 偽のH0を正しく棄却する確率。検出力 = 1 - 第二種誤り率。 |
| 中心極限定理 | サンプルサイズが大きくなるにつれてサンプル平均が正規分布に収束する。 |
| パラメトリック検定 | データの特定の分布（通常は正規分布）を仮定する。 |
| ノンパラメトリック検定 | 分布の仮定をしない。順位や符号を使って機能する。 |
