# サンプリング手法

> サンプリングは、AIが可能性の空間を探索する方法です。


## 学習目標

- 一様乱数のみを使って逆CDF、棄却、重点サンプリングをゼロから実装する
- 言語モデルのトークン生成のための温度、top-k、top-p（ニュークリアス）サンプリングを構築する
- 再パラメータ化トリックと、それがVAEでサンプリングを通じた誤差逆伝播を可能にする理由を説明する
- メトロポリス・ヘイスティングスMCMCを実行して非正規化ターゲット分布からサンプリングする

## 問題の背景

言語モデルがプロンプトを処理し終えると、語彙内のすべてのトークンに対応する50,000個のロジットのベクトルを生成します。1つを選択しなければなりません。どうやって？

常に最も確率の高いトークンを選ぶと、すべての応答が同一になります。決定論的で退屈です。一様ランダムに選ぶと、出力はでたらめになります。答えはこの両極端の間のどこかにあり、そのどこかはサンプリングによって制御されます。

サンプリングはテキスト生成に限られません。強化学習はトラジェクトリをサンプリングすることで方策勾配を推定します。VAEは学習した分布からサンプリングし、ランダム性を通じて誤差逆伝播することで潜在表現を学習します。拡散モデルはノイズをサンプリングし、反復的にノイズを除去することで画像を生成します。モンテカルロ法は閉形式の解を持たない積分を推定します。MCMCアルゴリズムは列挙不可能な高次元事後分布を探索します。

すべての生成AIシステムはサンプリングシステムです。サンプリング戦略は出力の品質、多様性、制御可能性を決定します。このレッスンでは、一様乱数から始めて現代のLLMや生成モデルを動かす技術まで、すべての主要サンプリング手法をゼロから構築します。

## 概念

### サンプリングが重要な理由

サンプリングはAIと機械学習全体で4つの基本的な役割を果たします：

**生成。** 言語モデル、拡散モデル、GANはすべてサンプリングによって出力を生成します。サンプリングアルゴリズムは創造性、一貫性、多様性を直接制御します。温度、top-k、ニュークリアスサンプリングはエンジニアが日常的に調整するノブです。

**学習。** 確率的勾配降下法はミニバッチをサンプリングします。ドロップアウトは無効化するニューロンをサンプリングします。データ拡張はランダムな変換をサンプリングします。重点サンプリングは強化学習（PPO、TRPO）で勾配の分散を減らすためにサンプルを再重み付けします。

**推定。** MLの多くの量には閉形式の解がありません。データ分布上の期待損失、エネルギーベースモデルの分配関数、ベイズ推論の証拠。モンテカルロ推定はこれらすべてをサンプルを平均することで近似します。

**探索。** MCMCアルゴリズムはベイズ推論の事後分布を探索します。進化的戦略はパラメータの摂動をサンプリングします。トンプソンサンプリングはバンディット問題での探索と活用のバランスをとります。

核心的な課題：単純な分布（一様、正規）から直接サンプリングできるだけです。それ以外のすべてには、単純なサンプルをターゲット分布からのサンプルに変換する方法が必要です。

### 一様ランダムサンプリング

すべてのサンプリング手法はここから始まります。一様乱数生成器は[0, 1)の値を生成し、等長の任意の部分区間は等確率を持ちます。

```
U ~ Uniform(0, 1)

P(a <= U <= b) = b - a    ただし 0 <= a <= b <= 1

性質：
  E[U] = 0.5
  Var(U) = 1/12
```

n個のアイテムの集合から一様サンプリングするには、Uを生成してfloor(n * U)を返します。連続範囲[a, b]からサンプリングするには、a + (b - a) * Uを計算します。

重要な洞察：1つの一様乱数は任意の分布から1つのサンプルを生成するのにちょうど適切な量のランダム性を含んでいます。トリックは適切な変換を見つけることです。

### 逆CDF法（逆変換サンプリング）

累積分布関数（CDF）は値を確率にマッピングします：

```
F(x) = P(X <= x)

性質：
  Fは非減少
  F(-inf) = 0
  F(+inf) = 1
  Fは実数直線を[0, 1]にマッピングする
```

逆CDFは確率を値に戻します。U ~ Uniform(0, 1)ならば、X = F_inverse(U)はターゲット分布に従います。

```
アルゴリズム：
  1. u ~ Uniform(0, 1) を生成する
  2. F_inverse(u) を返す

機能する理由：
  P(X <= x) = P(F_inverse(U) <= x) = P(U <= F(x)) = F(x)
```

**指数分布の例：**

```
PDF: f(x) = lambda * exp(-lambda * x),   x >= 0
CDF: F(x) = 1 - exp(-lambda * x)

F(x) = u を x について解く：
  u = 1 - exp(-lambda * x)
  exp(-lambda * x) = 1 - u
  x = -ln(1 - u) / lambda

(1 - U) と U は同じ分布を持つため：
  x = -ln(u) / lambda
```

逆CDFを閉形式で書ける場合は完璧に機能します。正規分布には閉形式の逆CDFがないため、他の方法（ボックス＝ミュラー法、または数値近似）を使います。

**離散版：** 離散分布では、CDFを累積和として構築し、Uを生成して、累積和がUを超える最初のインデックスを見つけます。これがレッスン06の`sample_categorical`が機能する仕組みです。

### 棄却サンプリング

CDFを逆転できないが定数まで目標PDFを評価できる場合、棄却サンプリングが機能します。

```
ターゲット分布：p(x)  （評価可能、正規化されていない場合もある）
提案分布：q(x)  （サンプリング可能）
上界：すべてのxに対してp(x) <= M * q(x) となるM

アルゴリズム：
  1. x ~ q(x) をサンプリングする
  2. u ~ Uniform(0, 1) をサンプリングする
  3. u < p(x) / (M * q(x)) ならばxを採択する
  4. それ以外は棄却して手順1に戻る

採択率 = 1/M
```

上界Mが小さいほど採択率が高くなります。低次元（1〜3次元）では棄却サンプリングはうまく機能します。高次元では、提案の体積のほとんどが棄却されるため、採択率が指数関数的に低下します。これが棄却サンプリングの次元の呪いです。

**例：切断正規分布からのサンプリング。** 切断範囲上の一様提案を使います。封筒Mはその範囲での正規PDFの最大値です。

**例：半円からのサンプリング。** 境界矩形内で一様に提案します。点が半円の内側に落ちれば採択します。これがモンテカルロがpiを計算する方法です：採択率は面積比pi/4に等しくなります。

### 重点サンプリング

ターゲット分布p(x)からのサンプルが必要なのではなく、p(x)の下での期待値を推定する必要があり、異なる分布q(x)からのサンプルがある場合があります。

```
目標：E_p[f(x)] = integral of f(x) * p(x) dx を推定する

書き換え：
  E_p[f(x)] = integral of f(x) * (p(x)/q(x)) * q(x) dx
            = E_q[f(x) * w(x)]

ここで w(x) = p(x) / q(x)  は重点重みである。

推定量：
  E_p[f(x)] ~ (1/N) * sum(f(x_i) * w(x_i))    ただし x_i ~ q(x)
```

これは強化学習において重要です。PPO（近接方策最適化）では、古い方策pi_oldの下でトラジェクトリを収集しますが、新しい方策pi_newを最適化したいのです。重点重みはpi_new(a|s) / pi_old(a|s)です。PPOはこれらの重みをクリップして、新しい方策が古い方策から大きく逸脱しないようにします。

重点サンプリング推定量の分散はqがpにどれだけ似ているかによります。qがpと大きく異なる場合、いくつかのサンプルが巨大な重みを得て推定値を支配します。自己正規化重点サンプリングはこの問題を減らすために重みの和で割ります：

```
E_p[f(x)] ~ sum(w_i * f(x_i)) / sum(w_i)
```

### モンテカルロ推定

モンテカルロ推定はランダムサンプルを平均することで積分を近似します。大数の法則が収束を保証します。

```
目標：領域D上の I = integral of g(x) dx を推定する

方法：
  1. Dから x_1, ..., x_N を一様サンプリングする
  2. I ~ (Dの体積 / N) * sum(g(x_i))

誤差：次元に依存せず O(1 / sqrt(N))
```

誤差率は次元に依存しません。これがグリッドベースの積分が不可能な高次元でモンテカルロ法が支配する理由です。

**piの推定：**

```
(x, y) を [-1, 1] x [-1, 1] から一様にサンプリングする
単位円の内側に落ちる数を数える：x^2 + y^2 <= 1
pi ~ 4 * (内側の数) / (合計数)
```

**期待値の推定：**

```
E[f(X)] ~ (1/N) * sum(f(x_i))    ただし x_i ~ p(x)

サンプル平均は真の期待値に収束する。
推定量の分散 = Var(f(X)) / N
```

### マルコフ連鎖モンテカルロ（MCMC）：メトロポリス・ヘイスティングス

MCMCはターゲット分布p(x)を定常分布として持つマルコフ連鎖を構築します。十分なステップを経た後、連鎖からのサンプルは（近似的に）p(x)からのサンプルになります。

```
ターゲット：p(x)  （正規化定数まで既知）
提案：q(x'|x)  （現在の状態を与えられたとき次の状態を提案する方法）

メトロポリス・ヘイスティングスアルゴリズム：
  1. 何らかのx_0から開始する
  2. t = 1, 2, ..., T に対して：
     a. x' ~ q(x'|x_t) を提案する
     b. 採択比を計算する：
        alpha = [p(x') * q(x_t|x')] / [p(x_t) * q(x'|x_t)]
     c. min(1, alpha) の確率で採択する：
        - u < alpha の場合（u ~ Uniform(0,1)）：x_{t+1} = x'
        - それ以外：x_{t+1} = x_t
  3. 最初のBサンプルを捨てる（バーンイン）
  4. 残りのサンプルを返す
```

対称的な提案（q(x'|x) = q(x|x')）の場合、比はp(x')/p(x)に簡略化されます。これが元のメトロポリスアルゴリズムです。

**機能する理由。** 採択規則が詳細釣合を保証します：xにいてx'に移動する確率はx'にいてxに移動する確率に等しい。詳細釣合はp(x)が連鎖の定常分布であることを意味します。

**実際の考慮事項：**
- バーンイン：連鎖が平衡に達する前の初期サンプルを捨てる
- 間引き：自己相関を減らすためにk番目ごとのサンプルを保持する
- 提案スケール：小さすぎると連鎖がゆっくり動く（高採択率、遅い探索）、大きすぎるとほとんどの提案が棄却される（低採択率、その場に止まる）
- 高次元でのガウス提案の最適採択率はおよそ0.234

### ギブスサンプリング

ギブスサンプリングは多変量分布のためのMCMCの特殊ケースです。すべての次元で同時に移動を提案する代わりに、各変数を条件付き分布から1つずつ更新します。

```
ターゲット：p(x_1, x_2, ..., x_d)

アルゴリズム：
  各反復tに対して：
    x_1^{t+1} ~ p(x_1 | x_2^t, x_3^t, ..., x_d^t) をサンプリングする
    x_2^{t+1} ~ p(x_2 | x_1^{t+1}, x_3^t, ..., x_d^t) をサンプリングする
    ...
    x_d^{t+1} ~ p(x_d | x_1^{t+1}, x_2^{t+1}, ..., x_{d-1}^{t+1}) をサンプリングする
```

ギブスサンプリングは各条件付き分布p(x_i | x_{-i})からサンプリングできることを必要とします。これは多くのモデルで簡単です：
- ベイジアンネットワーク：条件付き分布はグラフ構造から従う
- ガウス混合モデル：条件付き分布はガウス分布
- イジングモデル：各スピンの条件付き分布はその隣接ノードのみに依存する

正確な条件付き分布からのサンプリングは自動的に詳細釣合を満たすため、採択率は常に1（すべての提案が採択される）です。

**限界。** 変数が高度に相関している場合、一度に1つの変数を更新すると分布を通じた大きな対角移動ができないため、ギブスサンプリングは遅く混合します。

### 温度サンプリング（LLMで使用）

言語モデルは語彙内の各トークンのロジットz_1, ..., z_Vを出力します。Softmaxはこれらを確率に変換します。温度はsoftmax前にロジットをスケールします：

```
p_i = exp(z_i / T) / sum(exp(z_j / T))

T = 1.0：標準softmax（元の分布）
T -> 0：  argmax（決定論的、常に最高ロジットを選ぶ）
T -> inf：一様分布（すべてのトークンが等確率）
T < 1.0：分布を鋭くする（より確信的、多様性が低い）
T > 1.0：分布を平坦にする（より不確実、多様性が高い）
```

**機能する理由。** T < 1でロジットを割ると、ロジット間の差が増幅されます。z_1 = 2でz_2 = 1の場合、T = 0.5で割るとz_1/T = 4、z_2/T = 2となり、ギャップが大きくなります。softmax後、最高ロジットのトークンがより大きなシェアを得ます。

**実際には：**
- T = 0.0：貪欲デコーディング、事実的Q&Aに最適
- T = 0.3〜0.7：わずかに創造的、コード生成に良い
- T = 0.7〜1.0：バランス、一般的な会話に良い
- T = 1.0〜1.5：創作文章、ブレインストーミング
- T > 1.5：ますますランダムになり、ほとんど有用でない

温度はどのトークンが可能かを変えません。各トークンに割り当てられる確率質量を変えます。

### Top-kサンプリング

Top-kサンプリングは候補セットを最も高い確率を持つk個のトークンに制限し、次にその制限されたセットから再正規化してサンプリングします。

```
アルゴリズム：
  1. すべてのVトークンのsoftmax確率を計算する
  2. トークンを確率で並び替える（降順）
  3. 上位k個のトークンのみを保持する
  4. 再正規化：p_i' = p_i / sum(p_j for j in top-k)
  5. 再正規化された分布からサンプリングする

k = 1：  貪欲デコーディング
k = V：  フィルタリングなし（標準サンプリング）
k = 40：典型的な設定、ありそうにないトークンの長いテールを除去
```

Top-kは語彙分布の長いテールに存在する非常にありそうにないトークン（誤字、ナンセンス）をモデルが選択するのを防ぎます。問題：コンテキストに関係なくkは固定です。モデルが確信的（1つのトークンが95%の確率を持つ）な場合、k = 40はまだ39の代替を許します。モデルが不確実（確率が1000のトークンに広がる）な場合、k = 40は妥当な選択肢を切り捨てます。

### Top-p（ニュークリアス）サンプリング

Top-pサンプリングは候補セットサイズを動的に調整します。固定数のトークンを保持する代わりに、累積確率がpを超える最小セットのトークンを保持します。

```
アルゴリズム：
  1. すべてのVトークンのsoftmax確率を計算する
  2. トークンを確率で並び替える（降順）
  3. 上位k個の確率の和 >= p となる最小kを見つける
  4. それらk個のトークンのみを保持する
  5. 再正規化してサンプリングする

p = 0.9：確率質量の90%をカバーするトークンを保持
p = 1.0：フィルタリングなし
p = 0.1：非常に制限的、ほぼ貪欲
```

モデルが確信的な場合、ニュークリアスサンプリングは少ないトークン（おそらく2〜3個）を保持します。モデルが不確実な場合、多く（おそらく200個）を保持します。この適応的な動作がニュークリアスサンプリングが一般的にtop-kより優れたテキストを生成する理由です。

**一般的な組み合わせ：**
- 温度0.7 + top-p 0.9：汎用的な良い設定
- 温度0.0（貪欲）：決定論的タスクに最適
- 温度1.0 + top-k 50：Fan et al.（2018）元論文の設定

Top-kとtop-pは組み合わせられます。まずtop-kを適用し、次に残りのセットにtop-pを適用します。

### 再パラメータ化トリック（VAEで使用）

変分オートエンコーダ（VAE）は入力を潜在空間の分布にエンコードし、その分布からサンプリングし、サンプルをデコードして元に戻すことで学習します。問題：サンプリング操作を通じて誤差逆伝播できません。

```
標準サンプリング（微分不可能）：
  z ~ N(mu, sigma^2)

  ランダム性が勾配の流れをブロックする。
  d/d_mu [N(mu, sigma^2) からのサンプル] = ???
```

再パラメータ化トリックはランダム性をパラメータから分離します：

```
再パラメータ化サンプリング：
  epsilon ~ N(0, 1)          （固定ランダムノイズ、パラメータなし）
  z = mu + sigma * epsilon   （パラメータの決定論的関数）

  今、zはmuとsigmaの決定論的で微分可能な関数である。
  d(z)/d(mu) = 1
  d(z)/d(sigma) = epsilon

  勾配はmuとsigmaを通じて流れる。
```

これはN(mu, sigma^2)がmu + sigma * N(0, 1)と同じ分布を持つから機能します。重要な洞察：ランダム性をパラメータなしのソース（epsilon）に移動し、サンプルをパラメータの微分可能な変換として表現します。

**VAE学習ループにおいて：**
1. エンコーダは各入力についてmuとlog(sigma^2)を出力する
2. epsilon ~ N(0, 1) をサンプリングする
3. z = mu + sigma * epsilon を計算する
4. zをデコードして入力を再構成する
5. ステップ4、3、2、1を通じて誤差逆伝播する（ステップ3が微分可能なので可能）

再パラメータ化トリックなしでは、VAEは標準的な誤差逆伝播で学習できません。この一つの洞察がVAEを実用的にしました。

### ガンベル・ソフトマックス（微分可能カテゴリカルサンプリング）

再パラメータ化トリックは連続分布（ガウス）に機能します。離散カテゴリカル分布には異なるアプローチが必要です。ガンベル・ソフトマックスはカテゴリカルサンプリングへの微分可能な近似を提供します。

**ガンベル・マックストリック（微分不可能）：**

```
対数確率log(p_1), ..., log(p_k)を持つカテゴリカル分布からサンプリングするには：
  1. 各カテゴリについて g_i ~ Gumbel(0, 1) をサンプリングする
     （g = -log(-log(u))、ここでu ~ Uniform(0, 1)）
  2. argmax(log(p_i) + g_i) を返す

これは厳密なカテゴリカルサンプルを生成する。
```

**ガンベル・ソフトマックス（微分可能な近似）：**

```
ハードargmaxをソフトsoftmaxで置き換える：
  y_i = exp((log(p_i) + g_i) / tau) / sum(exp((log(p_j) + g_j) / tau))

tau（温度）が近似を制御する：
  tau -> 0：  one-hotベクトルに近づく（ハードカテゴリカル）
  tau -> inf：一様分布に近づく（1/k, 1/k, ..., 1/k）
  tau = 1.0： ソフトな近似
```

ガンベル・ソフトマックスは離散サンプルの連続的な緩和を生成します。出力はハードなone-hotの代わりに確率ベクトル（ソフトone-hot）です。勾配はsoftmaxを通じて流れます。学習中のフォワードパスでは「ストレートスルー」推定量を使えます：フォワードパスにはハードargmaxを使いますが、バックワードパスにはソフトなガンベル・ソフトマックス勾配を使います。

**応用：**
- VAEの離散潜在変数
- ニューラルアーキテクチャ探索（離散操作の選択）
- ハードアテンション機構
- 離散行動を持つ強化学習

### 層別サンプリング

標準モンテカルロサンプリングは偶然にサンプル空間にギャップを残す可能性があります。層別サンプリングは空間を層に分割し各層からサンプリングすることで均等なカバレッジを強制します。

```
標準モンテカルロ：
  [0, 1] からN点を一様にサンプリングする
  一部の領域にはクラスター、他の領域にはギャップが生じる可能性がある

層別サンプリング：
  [0, 1] をN個の等しい層に分割する：[0, 1/N)、[1/N、2/N)、...、[(N-1)/N、1)
  各層内から一様に1点をサンプリングする
  x_i = (i + u_i) / N   ここでu_i ~ Uniform(0, 1)、i = 0、...、N-1
```

層別サンプリングは常に標準モンテカルロと比べて分散が低いか等しいです：

```
Var(層別) <= Var(標準モンテカルロ)

f(x)が滑らかに変化するとき改善が最大。
区分的定数関数の場合、層別サンプリングは厳密。
```

**応用：**
- 数値積分（準モンテカルロ）
- 学習データ分割（各フォールドのクラスバランスを確保）
- 層別化を使った重点サンプリング（両技術の組み合わせ）
- NeRF（Neural Radiance Fields）はカメラ光線に沿った層別サンプリングを使用

### 拡散モデルとの関係

拡散モデルはサンプリングプロセスを通じて画像を生成します。フォワードプロセスはT ステップにわたって画像にガウスノイズを追加し、純粋なノイズになるまで続きます。リバースプロセスはノイズ除去を学習し、段階的に元の画像を回復します。

```
フォワードプロセス（既知）：
  x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * epsilon
  ここで epsilon ~ N(0, I)

  T ステップ後：x_T ~ N(0, I)（純粋なノイズ）

リバースプロセス（学習済み）：
  x_{t-1} = (1/sqrt(alpha_t)) * (x_t - (1 - alpha_t)/sqrt(1 - alpha_bar_t) * epsilon_theta(x_t, t)) + sigma_t * z
  ここで z ~ N(0, I)

  各ノイズ除去ステップはサンプリングステップである。
```

このレッスンの手法との関係：
- 各ノイズ除去ステップは再パラメータ化トリックを使用（ノイズをサンプリングし、決定論的変換を適用）
- ノイズスケジュール{alpha_t}は温度アニーリングの一形態を制御する
- 学習はELBO（証拠下限）を近似するモンテカルロ推定を使用
- 拡散モデルにおける祖先サンプリングはマルコフ連鎖（各ステップは現在の状態のみに依存）

画像生成プロセス全体は反復サンプリングです：ノイズから始まり、各ステップで学習済みノイズ除去モデルを条件として、少しノイズが少ない版をサンプリングします。

```python
        x = proposal_sample()
        u = random.random()
        if u < target_pdf(x) / (M * proposal_pdf(x)):
```

```python
def importance_sampling_estimate(f, target_pdf, proposal_pdf, proposal_sample, n):
    total = 0
    for _ in range(n):
        x = proposal_sample()
        w = target_pdf(x) / proposal_pdf(x)
        total += f(x) * w
    return total / n
```

一様提案を使って正規分布の下でE[X^2]を推定します。既知の答え（mu^2 + sigma^2）と比較します。

### ステップ4：モンテカルロによるpiの推定

```python
def monte_carlo_pi(n):
    inside = 0
    for _ in range(n):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        if x*x + y*y <= 1:
            inside += 1
    return 4 * inside / n
```

### ステップ5：メトロポリス・ヘイスティングスMCMC

```python
def metropolis_hastings(target_log_pdf, proposal_sample, proposal_log_pdf, x0, n_samples, burn_in):
    samples = []
    x = x0
    for i in range(n_samples + burn_in):
        x_new = proposal_sample(x)
        log_alpha = (target_log_pdf(x_new) + proposal_log_pdf(x, x_new)
                     - target_log_pdf(x) - proposal_log_pdf(x_new, x))
        if math.log(random.random()) < log_alpha:
            x = x_new
        if i >= burn_in:
            samples.append(x)
    return samples
```

二峰性分布（2つのガウス分布の混合）からサンプリングします。連鎖の軌跡を可視化します。

### ステップ6：ギブスサンプリング

```python
def gibbs_sampling_2d(conditional_x_given_y, conditional_y_given_x, x0, y0, n_samples, burn_in):
    x, y = x0, y0
    samples = []
    for i in range(n_samples + burn_in):
        x = conditional_x_given_y(y)
        y = conditional_y_given_x(x)
        if i >= burn_in:
            samples.append((x, y))
    return samples
```

```python
def softmax(logits):
    max_l = max(logits)
    exps = [math.exp(z - max_l) for z in logits]
    total = sum(exps)
    return [e / total for e in exps]

def temperature_sample(logits, temperature):
    scaled = [z / temperature for z in logits]
    probs = softmax(scaled)
    return sample_from_probs(probs)
```

### ステップ8：Top-kとtop-pサンプリング

```python
def top_k_sample(logits, k):
    indexed = sorted(enumerate(logits), key=lambda x: -x[1])
    top = indexed[:k]
    top_logits = [l for _, l in top]
    probs = softmax(top_logits)
    idx = sample_from_probs(probs)
    return top[idx][0]

def top_p_sample(logits, p):
    probs = softmax(logits)
    indexed = sorted(enumerate(probs), key=lambda x: -x[1])
    cumsum = 0
    selected = []
    for token_idx, prob in indexed:
        cumsum += prob
        selected.append((token_idx, prob))
        if cumsum >= p:
            break
    sel_probs = [pr for _, pr in selected]
    total = sum(sel_probs)
    sel_probs = [pr / total for pr in sel_probs]
    idx = sample_from_probs(sel_probs)
    return selected[idx][0]
```

### ステップ9：再パラメータ化トリック

```python
def reparam_sample(mu, sigma):
    epsilon = random.gauss(0, 1)
    return mu + sigma * epsilon

def reparam_gradient(mu, sigma, epsilon):
    dz_dmu = 1.0
    dz_dsigma = epsilon
    return dz_dmu, dz_dsigma
```

### ステップ10：ガンベル・ソフトマックス

```python
def gumbel_sample():
    u = random.random()
    return -math.log(-math.log(u))

def gumbel_softmax(logits, temperature):
    gumbels = [math.log(p) + gumbel_sample() for p in logits]
    return softmax([g / temperature for g in gumbels])
```

## キー用語

| 用語 | よく言われる説明 | 実際の意味 |
|------|----------------|------------|
| サンプリング | 「ランダムな値を描画すること」 | 確率分布に従って値を生成すること。すべての生成AIの背後にある仕組み |
| 一様分布 | 「すべてが等確率」 | [a, b]のすべての値が等しい確率密度1/(b-a)を持つ。すべてのサンプリング手法の出発点 |
| 逆CDF | 「確率変換」 | F_inverse(U)は一様サンプルを既知のCDFを持つ任意の分布からのサンプルに変換する。厳密で効率的 |
| 棄却サンプリング | 「提案して採択/棄却する」 | 単純な提案から生成し、目標/提案比に比例した確率で採択する。厳密だがサンプルを無駄にする |
| 重点サンプリング | 「サンプルに重みを付ける」 | 各サンプルをp(x)/q(x)で重み付けすることでq(x)からのサンプルを使ってp(x)の下での期待値を推定する。RLのPPOの核心 |
| モンテカルロ | 「ランダムサンプルを平均する」 | 積分をサンプル平均で近似する。誤差O(1/sqrt(N))は次元に依存しない |
| MCMC | 「収束するランダムウォーク」 | ターゲット分布を定常分布として持つマルコフ連鎖を構築する。メトロポリス・ヘイスティングスが基礎アルゴリズム |
| メトロポリス・ヘイスティングス | 「上り坂を採択、ときには下り坂も」 | 移動を提案し、密度比に基づいて採択する。詳細釣合がターゲット分布への収束を保証する |
| ギブスサンプリング | 「一度に1変数ずつ」 | 他を固定して条件付き分布から各変数を更新する。100%採択率 |
| 温度 | 「信頼度ノブ」 | softmax前にロジットをTで割る。T<1は鋭くする（より確信的）、T>1は平坦にする（より多様）|
| Top-kサンプリング | 「上位kを保持」 | 上位k個の確率トークン以外をゼロにし、再正規化してサンプリングする。固定候補セットサイズ |
| ニュークリアスサンプリング（top-p） | 「確率の高いものを保持」 | 累積確率がpを超える最小のトークンセットを保持する。適応的な候補セットサイズ |
| 再パラメータ化トリック | 「ランダム性を外に出す」 | z = mu + sigma * epsilonと書く（epsilon ~ N(0,1)）。サンプリングを微分可能にする。VAE学習に必須 |
| ガンベル・ソフトマックス | 「ソフトカテゴリカルサンプリング」 | ガンベルノイズ + 温度付きsoftmaxを使ったカテゴリカルサンプリングへの微分可能な近似 |
| 層別サンプリング | 「強制的なカバレッジ」 | サンプル空間を層に分割し、各層からサンプリングする。常にナイーブなモンテカルロより分散が低い |
| バーンイン | 「ウォームアップ期間」 | 連鎖が定常分布に達する前の初期MCMCサンプルを捨てる |
| 詳細釣合 | 「可逆性条件」 | p(x) * T(x->y) = p(y) * T(y->x)。pがマルコフ連鎖の定常分布であるための十分条件 |
| 拡散サンプリング | 「反復的ノイズ除去」 | ノイズから始まり、学習済みノイズ除去ステップを適用してデータを生成する。各ステップは条件付きサンプリング操作 |
