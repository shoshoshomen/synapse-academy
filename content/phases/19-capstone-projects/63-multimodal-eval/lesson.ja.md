# マルチモーダル評価

> 訓練はループの半分だ。もう半分は測定だ。このレッスンはプリミティブから3つの評価面を構築する：R@1、R@5、R@10 として報告される画像キャプション検索、正確一致精度として報告されるビジュアル質問応答（VQA）、BLEU-4 として報告される画像キャプション生成。各メトリクスはモデルの出力に対する関数であり、合成評価スイートは数秒で実行される。


## 学習目標

- 画像とキャプション埋め込みの類似度行列から Recall@K を計算する。
- 固定の回答語彙に（画像、質問）ペアをマッピングするモデルから正確一致 VQA 精度を計算する。
- 外部ライブラリなしに生成されたトークンシーケンスと参照トークンシーケンスから BLEU-4 を計算する。
- レッスン62の訓練済みモデルの上に構築した合成スイートに対して3つの評価をすべて実行する。

## 問題

マルチモーダルモデルは訓練損失が停滞したときに完成と宣言したくなる誘惑がある。訓練損失は訓練分布への適合を測定し、保留バッチでペアをランク付けする能力、質問に答える能力、人間が受け入れるキャプションを書く能力を測定しない。3つの評価面が標準だ：

- **検索（R@1、R@5、R@10）。** クエリキャプションの結合埋め込みを構築し、コサインで評価プール内のすべての画像をランク付けし、マッチする画像がトップ1、トップ5、トップ10に入るかを報告する。対称（画像テキスト）形式も同様に実行する。
- **ビジュアル質問応答（正確一致）。** （画像、質問）が与えられると、モデルは回答トークンを出力する。正確一致はサンプルごとのビット：予測された回答は参照回答と等しいか？評価セット全体で平均する。
- **キャプション生成（BLEU-4）。** キャプションを生成する。参照キャプションに対して1グラムから4グラムの精度の幾何平均を簡潔さのペナルティとともに計算する。マルチ参照が標準（1画像、複数参照キャプション）。

各メトリクスは薄い関数だ。このレッスンではすべてをコードで構築し、数学が具体的で表面が制御下にある。実際のベンチマークスイート（MS-COCO、VQA v2、GQA、OK-VQA）は同じ関数形状に接続される。

## コンセプト

```mermaid
flowchart TB
  Model[訓練済みマルチモーダルモデル] --> Embed[評価セットの結合埋め込み]
  Embed --> Sim[類似度行列]
  Sim --> R1[R@1]
  Sim --> R5[R@5]
  Sim --> R10[R@10]
  Model --> VQA[質問ごとの回答トークン予測]
  VQA --> EM[正確一致精度]
  Model --> Caps[生成されたキャプション]
  Caps --> BLEU[参照に対する BLEU-4]
```

### 類似度行列から Recall@K

画像埋め込みとキャプション埋め込みの `(N, N)` コサイン類似度行列を構築する。各行について、降順類似度で列をソートする。Recall@K は対角列インデックスがトップ K 位置内に入る行の割合だ。対称 Recall@K（キャプション対画像）は転置行列で計算される。両方の数値が報告される。N=100 の評価で R@1 = 0.6 とは、100のキャプションのうち60が最もマッチする画像をトップマッチとして検索したことを意味する。

### VQA 正確一致

各（画像、質問、回答）について、画像をエンコードし、質問を埋め込み、デコーダー経由でフューズし、次のトークンを読み出す。予測されたトークン ID が参照 ID と比較され、等しければ正解。評価セットで平均する。実際の VQA データセットでは質問ごとに複数のアノテーションを持ち、ソフトアキュラシー式を使用する（10人中3人以上が同意すれば1.0、それ以下はスケール）。このレッスンでは明確さのために単一回答の正確一致を使用する。

### BLEU-4

```text
BLEU-4 = BP * exp(mean(log p1, log p2, log p3, log p4))
```

ここで `p_n` は修正 n グラム精度（任意の参照に現れる生成 n グラムのクリップされた数を総生成 n グラム数で割ったもの）で、`BP` は簡潔さのペナルティ：

```text
BP = 1                生成長 > 参照長の場合
   = exp(1 - r/g)     それ以外。r は参照長、g は生成長
```

`p_n` がゼロになる小さなサンプルにはスムージングが必要だ。実装では Chen と Cherry の「メソッド1」を使用する（ゼロカウントの分子と分母に1を加える）。これが低カウント領域で最も安全なデフォルトだ。

### 合成評価スイート

50サンプルの評価スイートはレッスン62で使用されたモックコーパスパターンと同じものから保留シードでメモリ上に構築される。スイートを構成する3つのリスト：

- `pairs`：検索用の50の（画像、caption_ids）ペア。
- `vqa`：50の（画像、question_ids、answer_id）トリプル。
- `caps`：画像ごとに最大3つの参照を持つ50の（画像、[reference_caption_ids, ...]）エントリ。

スイートはシードから決定論的で、訓練コーパスから保留されているため、メトリクスはモデルが見たことのないデータで計算される。スイートを JSON に永続化することは演習として残されている（以下参照）。

| メトリクス | 範囲 | ランダムベースライン（N=50） |
|--------|-------|------------------------|
| R@1 | 0〜1 | 0.02（1 / N） |
| R@5 | 0〜1 | 0.10 |
| R@10 | 0〜1 | 0.20 |
| VQA EM | 0〜1 | 1 / vocab |
| BLEU-4 | 0〜1 | 小さいがゼロではない |

合成データでの50ステップ訓練実行では、メトリクスが高くなることは期待されていない。ランダムベースラインを上回ることが期待され、デモはそれを確認する。

## 実装する

`code/main.py` が実装するもの：

- `recall_at_k(sim_matrix, k)`：両方向で `[0, 1]` の浮動小数点を返す。
- `vqa_exact_match(predictions, references)`：`int` 等価の平均を返す。
- `bleu4(generated, references, smoothing=True)`：マルチ参照サポート付き。
- `build_eval_suite(seed, n_samples, vocab_size, max_len)`：3つの決定論的評価リストを返す。
- `evaluate(model, suite)`：3つのメトリクスすべてを実行して数値の `dict` を返す。
- デモ：レッスン62の新しく初期化されたマルチモーダルモデルをロードして評価し、50ステップ訓練してから再評価して、ビフォーアフターのメトリクスを表示する。

実行方法：

```bash
python3 code/main.py
```

出力：ビフォーアフターのメトリクステーブルで、検索がほぼランダムからモデルの学習済みシグナルに向かって改善し、VQA がランダムを上回り、BLEU-4 が改善する（合成構造は4グラム精度の向上に十分）。

## 使ってみる

各メトリクスはプロダクションのベンチマークに直接マッピングされる：

- **検索。** MS-COCO 5K val、Flickr30K、ImageNet ゼロショットはすべて同じ類似度行列での R@K 問題だ。合成評価を実際のファイルで置き換えれば、関数シグネチャは変わらない。
- **VQA。** VQA v2、GQA、OK-VQA は同じ正確一致形状を使用する（VQA v2 の単一回答EM の代わりにソフトアキュラシーを使用）。
- **BLEU-4。** MS-COCO キャプション生成、NoCaps、Flickr30K キャプション生成はすべて BLEU-4 に加えて CIDEr と METEOR を使用する。CIDEr の追加はもう1つの関数だ。

実際のベンチマークでは、`build_eval_suite` を実際のローダーで置き換えて関数本体を保持する。数学はベンチマーク非依存だ。

## テスト

`code/test_main.py` がカバーするもの：

- recall@k が完全な単位類似度行列で1.0、k < N の反転行列で0.0を返す
- recall@k が `k <= N` の上限を尊重する
- bleu4 が生成が参照のいずれかと完全に一致するとき1.0を返す
- bleu4 が異なる語彙では0.0を返す
- vqa 正確一致が等しいペアの割合と等しい
- build_eval_suite が期待されるペア数、VQA アイテム数、キャプションエントリ数を返す

実行方法：

```bash
python3 -m unittest code/test_main.py
```

## 演習

1. キャプションメトリクスに CIDEr を追加する。CIDEr は n グラムに TF-IDF 重み付けを使用し、情報量の多いトークンを報酬する。

2. ソフトアキュラシー VQA を実装する：質問ごとに複数の人間の回答があり、精度は一致する場合 `min(human_count / 3, 1)` となる。VQA v2 を再現する。

3. 空の生成シーケンスをクラッシュなしに処理する `bleu4` の NaN 安全バリアントを追加する。

4. R@K と並べて平均逆数ランク（MRR）を計算する。MRR はトップ K を超えた正しいアイテムの位置に敏感で、R@K はトップ K に入るかどうかに敏感だ。

5. 訓練中の5つのチェックポイント（ステップ0、10、20、30、40、50）でモデルに対して評価を実行し、学習曲線をプロットする。メトリクスの軌跡が損失の軌跡を追うことを確認する。

## キーワード

| 用語 | 意味 |
|------|---------------|
| R@K | 正しいマッチがトップ K 結果に入るクエリの割合 |
| 正確一致 | 最もシンプルな VQA スコアリング：予測回答が参照と等しい |
| BLEU-4 | 簡潔さペナルティ付きの1〜4グラム精度の幾何平均 |
| マルチ参照 | キャプションメトリクスが画像ごとに複数の参照キャプションを受け入れる |
| 保留 | 評価セットは訓練コーパスとは異なるシードからサンプリングされる |
